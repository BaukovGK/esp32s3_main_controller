# Назначенные Modbus-адреса устройств

> Это **carte officielle** — единственный источник истины для slave-адресов на шине RS-485 РО-установки.
> При изменении физической конфигурации редактировать только этот файл и `components/board_hal/include/board_config.h` (макросы `MB_ADDR_*`). Все драйверы должны брать адреса оттуда, а не хардкодить.

## Сводная таблица

| Slave addr | Устройство | Заводское default | Назначено | Макрос в коде | Комментарий |
|---:|---|---:|---:|---|---|
| **1** | Waveshare Modbus RTU PWM Input 8CH | 1 | **1** | `MB_ADDR_WAVESHARE_AI` ⚠️ | менять не нужно — default; ⚠️ переименовать в `MB_ADDR_WAVESHARE_PWM` (модуль PWM, не Analog) |
| **2** | УРЖ2КМ (4-канальный) | 1 | **2** | `MB_ADDR_URZH2KM` | сменить с 1 → 2 через ModBus Universal или через подрежим `05` на лицевой панели |
| **10** | СЛ21-100Т #1 «концентрат / пермеат-2» | 5 | **10** | `MB_ADDR_SL21_201` | сменить через меню «МВ интерфейс → Адрес» (см. п.5.16.2 РЭ) |
| **11** | СЛ21-100Т #2 «питание / пермеат-1» | 5 | **11** | `MB_ADDR_SL21_101` | сменить через меню «МВ интерфейс → Адрес» |
| **20** | KWS-306L #1 (3-фазный, **НД-насос**) | 1 | **20** | `MB_ADDR_KWS_PUMP_LP` ⚠️ TODO | назначить FC=06 в reg 0x4000 |
| **21** | KWS-306L #2 (3-фазный, **ВД-насос**) | 1 | **21** | `MB_ADDR_KWS_PUMP_HP` ⚠️ TODO | назначить FC=06 в reg 0x4000 |

⚠️ **Зарезервировано**, но не используется: 3..9, 12..19, 22..127. Для будущих расширений (например, второй УРЖ2КМ, дополнительная СЛ21, частотник насоса с Modbus, контроллер дозатора).

## Параметры связи (общие для всей шины)

| Параметр | Значение | Зачем именно так |
|---|---|---|
| Скорость | **9600 бод** | Минимум, который держат все 4 типа устройств. УРЖ2КМ имеет дискретный ряд {1.2, 2.4, 4.8, 9.6, 14.4, 19.2}; СЛ21 — {9.6, 19.2}; Waveshare PWM — {4.8, 9.6, 19.2, 38.4, 57.6, 115.2, 128, 256}; KWS — обычно 9.6. |
| Чётность | **None** | Waveshare и KWS обычно не поддерживают Even, СЛ21 нужно явно перевести в None через меню. |
| Стоп-биты | **1** | стандартный 8N1 |
| Inter-frame | ≥3.5 char (~4 мс) | Modbus RTU стандарт |

## Как сменить slave-адрес у каждого устройства

### Waveshare PWM Input 8CH (slave 1 — default, не меняется)
```
# Если всё-таки понадобится сменить с 1 на N — broadcast-командой:
00 06 40 00 00 N CRC16
# где N = 0x01..0xFF (1..255)
```
> **Важно:** перед командой отключить остальные слейвы от шины (broadcast 0x00 примут все).

### УРЖ2КМ (default 1 → назначить 2)
**Способ 1 (с лицевой панели):**
1. Войти в режим «ПРОГРАММИРОВАНИЕ» (нажать `→`, затем удерживая `→` нажать `ВВОД`).
2. Перейти в подрежим `05` («Сетевой адрес»).
3. Ввести значение `002`.
4. Выйти из режима программирования (для записи в энергонезависимую память).

**Способ 2 (через ModBus Universal от производителя):**
1. Подключить через RS-232/485 на адресе 001.
2. Открыть программу, окно «Параметры УРЖ2КМ».
3. Установить новый адрес, нажать «Записать».

### СЛ21-100Т (default 5 → назначить 10 / 11)
1. На лицевой панели прибора пролистать до окна «МВ интерфейс».
2. Выбрать параметр «Адрес», ввести `010` (или `011` для второго блока).
3. Параллельно проверить:
   - Скорость — должна быть `9600 бод` (по default может быть 19200 — переключить).
   - Паритет — должен быть `None` (если в меню СЛ21 нет «None», поставить «чётный» и в `mb_init` нашего ESP32 тоже выставить even — но это усложняет).
4. Сохранить через окно «Установки пользователя СОХРАНИТЬ» (см. п.5.19 РЭ).

### KWS-306L (default 1 → назначить 20 / 21)
**Только по одному прибору на шине одновременно!** Иначе оба ответят на default-адрес → конфликт.
```
# Подключить ТОЛЬКО первый KWS, послать broadcast:
00 06 40 00 00 14 CRC16   # адрес 0x0014 = 20

# Отключить первый, подключить второй:
00 06 40 00 00 15 CRC16   # адрес 0x0015 = 21

# Проверка чтением:
01 03 40 00 00 01 CRC16   # должен ответить уже с новым адресом
```
> KWS-серия не имеет физических кнопок для смены адреса — только через Modbus 0x06 в reg 0x4000.

## Рекомендуемые периоды опроса

| Slave | Период (мс) | Обоснование |
|---:|---:|---|
| 1 — Waveshare PWM 8CH | 200 | давление через PWM-датчики (если используются) — быстрая реакция на броски |
| 2 — УРЖ2КМ (расходы) | 1000 | расход меняется медленно, для PI-регулирования качества пермеата 1с достаточно |
| 2 — УРЖ2КМ (объёмы) | 5000 | накопленный объём, для счётчика-учёта |
| 10 — СЛ21 #1 | 500 | проводимость пермеата — критическая, для уставки CONDUCTIVITY_HIGH |
| 11 — СЛ21 #2 | 500 | то же |
| 20 — KWS-306L #1 | 2000 | электроэнергия меняется медленно, защита от перекоса фаз — раз в 2с хватит |
| 21 — KWS-306L #2 | 2000 | то же |

> Период < 500 мс при 9600 бод и 6+ slaves может вызывать пропуски опроса — есть запас.
