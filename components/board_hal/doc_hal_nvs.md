# hal_nvs.h / hal_nvs.c -- Обёртка NVS для хранения конфигурации

## Описание модуля

Модуль аппаратной абстракции для работы с энергонезависимым хранилищем (NVS -- Non-Volatile Storage) ESP32. Предоставляет упрощённый интерфейс для чтения и записи конфигурационных параметров различных типов: целые числа (`int32_t`), числа с плавающей точкой (`float`) и строки.

Все данные хранятся в NVS-пространстве имён (namespace) `"ro_plant"`. Каждая операция записи выполняет атомарный цикл: открытие -> запись -> фиксация (commit) -> закрытие. Каждая операция чтения: открытие -> чтение -> закрытие.

Модуль обрабатывает ситуацию повреждённого NVS-раздела: при ошибках `ESP_ERR_NVS_NO_FREE_PAGES` или `ESP_ERR_NVS_NEW_VERSION_FOUND` автоматически стирает раздел и повторно инициализирует NVS.

**Файлы:**
- Заголовок: `components/board_hal/include/hal_nvs.h`
- Реализация: `components/board_hal/hal_nvs.c`

## Функции

### hal_nvs_init

```c
esp_err_t hal_nvs_init(void);
```

**Описание:** Инициализация подсистемы NVS Flash. Выполняет следующие действия:

1. Вызывает `nvs_flash_init()` для инициализации NVS-раздела.
2. Если возвращена ошибка `ESP_ERR_NVS_NO_FREE_PAGES` (нет свободных страниц) или `ESP_ERR_NVS_NEW_VERSION_FOUND` (несовместимая версия формата):
   - Выводит предупреждение в лог
   - Стирает весь NVS-раздел через `nvs_flash_erase()` (с проверкой ошибки через `ESP_ERROR_CHECK`)
   - Повторно вызывает `nvs_flash_init()`
3. При успехе выводит информационное сообщение с именем namespace.

**Параметры:** Нет.

**Возвращаемое значение:**
- `ESP_OK` -- успешная инициализация (в том числе после стирания и повторной инициализации)
- Код ошибки ESP-IDF -- при неустранимой ошибке инициализации

**Важно:** При повреждении NVS-раздела все ранее сохранённые данные будут **безвозвратно утеряны** (стирание раздела).

### hal_nvs_set_i32

```c
esp_err_t hal_nvs_set_i32(const char *key, int32_t value);
```

**Описание:** Записывает 32-битное целое число со знаком в NVS по указанному ключу.

**Алгоритм работы:**
1. Открывает NVS-пространство `"ro_plant"` в режиме чтения-записи (`NVS_READWRITE`).
2. Записывает значение через `nvs_set_i32()`.
3. При успешной записи вызывает `nvs_commit()` для фиксации данных на flash.
4. Закрывает дескриптор NVS.

**Параметры:**

| Параметр | Тип | Описание |
|---|---|---|
| `key` | `const char *` | Строковый ключ NVS (максимум 15 символов, ограничение ESP-IDF) |
| `value` | `int32_t` | Значение для записи (от -2147483648 до 2147483647) |

**Возвращаемое значение:**
- `ESP_OK` -- успешная запись и фиксация
- Код ошибки ESP-IDF -- при ошибке открытия namespace, записи или фиксации

### hal_nvs_set_float

```c
esp_err_t hal_nvs_set_float(const char *key, float value);
```

**Описание:** Записывает число с плавающей точкой (`float`, 4 байта) в NVS по указанному ключу. Поскольку NVS не имеет встроенного типа для `float`, значение сохраняется как **blob** (бинарный объект) размером `sizeof(float)` = 4 байта.

**Алгоритм работы:**
1. Открывает NVS-пространство `"ro_plant"` в режиме чтения-записи.
2. Записывает значение через `nvs_set_blob()`, передавая указатель на `value` и размер `sizeof(float)`.
3. При успешной записи вызывает `nvs_commit()`.
4. Закрывает дескриптор NVS.

**Параметры:**

| Параметр | Тип | Описание |
|---|---|---|
| `key` | `const char *` | Строковый ключ NVS |
| `value` | `float` | Значение с плавающей точкой для записи |

**Возвращаемое значение:**
- `ESP_OK` -- успешная запись и фиксация
- Код ошибки ESP-IDF -- при ошибке

---

### hal_nvs_get_float

```c
esp_err_t hal_nvs_get_float(const char *key, float *value);
```

**Описание:** Читает число с плавающей точкой (`float`) из NVS по указанному ключу. Данные читаются как blob размером `sizeof(float)`.

**Алгоритм работы:**
1. Проверяет указатель `value` на NULL. При NULL возвращает `ESP_ERR_INVALID_ARG`.
2. Открывает NVS-пространство `"ro_plant"` в режиме только чтения.
3. Читает blob через `nvs_get_blob()` с ожидаемым размером `sizeof(float)`.
4. Закрывает дескриптор NVS.

**Параметры:**

| Параметр | Тип | Описание |
|---|---|---|
| `key` | `const char *` | Строковый ключ NVS для поиска |
| `value` | `float *` | [out] Указатель на переменную для записи прочитанного значения. Не должен быть NULL |

**Возвращаемое значение:**
- `ESP_OK` -- успешное чтение
- `ESP_ERR_INVALID_ARG` -- указатель `value` равен NULL
- `ESP_ERR_NVS_NOT_FOUND` -- ключ не найден в NVS
- Код ошибки ESP-IDF -- при других ошибках

### hal_nvs_get_str

```c
esp_err_t hal_nvs_get_str(const char *key, char *value, size_t max_len);
```

**Описание:** Читает строку из NVS по указанному ключу в предоставленный буфер.

**Алгоритм работы:**
1. Проверяет входные параметры: `value` не должен быть NULL, `max_len` не должен быть 0. При нарушении возвращает `ESP_ERR_INVALID_ARG`.
2. Открывает NVS-пространство `"ro_plant"` в режиме только чтения.
3. Читает строку через `nvs_get_str()`, передавая `max_len` как максимальный размер буфера.
4. Закрывает дескриптор NVS.

**Параметры:**

| Параметр | Тип | Описание |
|---|---|---|
| `key` | `const char *` | Строковый ключ NVS для поиска |
| `value` | `char *` | [out] Буфер для записи прочитанной строки. Не должен быть NULL |
| `max_len` | `size_t` | Максимальный размер буфера `value` в байтах (включая нулевой терминатор). Не должен быть 0 |

**Возвращаемое значение:**
- `ESP_OK` -- успешное чтение
- `ESP_ERR_INVALID_ARG` -- `value` равен NULL или `max_len` равен 0
- `ESP_ERR_NVS_NOT_FOUND` -- ключ не найден в NVS
- Код ошибки ESP-IDF -- при других ошибках (например, если буфер слишком мал)

## Примечания

- **Namespace `"ro_plant"`** -- единственное пространство имён, используемое модулем. Все ключи всех типов данных хранятся в этом пространстве.
- **Атомарность операций:** Каждая операция записи выполняет полный цикл open-write-commit-close. Это гарантирует, что данные зафиксированы на flash после каждого вызова, но увеличивает время выполнения и износ flash-памяти.
- **Хранение float:** NVS ESP-IDF не поддерживает тип `float` нативно, поэтому используется тип blob. Это означает, что значение хранится как 4-байтовый двоичный объект без метаданных о типе. При чтении blob другого размера результат будет непредсказуемым.
- **Ограничения ключей NVS:** Максимальная длина ключа -- 15 символов (ограничение ESP-IDF NVS).
- **Обработка ошибок при чтении:** Функции чтения (`get_*`) не выводят ошибки в лог при неудаче `nvs_open()` -- они просто возвращают код ошибки. Это нормально, так как `ESP_ERR_NVS_NOT_FOUND` является штатной ситуацией (ключ ещё не был записан).
- **Обработка ошибок при записи:** Функции записи (`set_*`) выводят ошибку в лог при неудаче `nvs_open()`, так как невозможность записи обычно является аномальной ситуацией.
- **Стирание при повреждении:** В `hal_nvs_init()` при обнаружении повреждённого раздела используется `ESP_ERROR_CHECK(nvs_flash_erase())`, что приведёт к **abort() при ошибке стирания**. Это осознанное решение: если даже стирание не удалось, нормальная работа системы невозможна.
