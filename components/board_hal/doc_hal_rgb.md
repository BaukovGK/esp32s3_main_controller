# hal_rgb — WS2812 RGB-LED для индикации состояния (Phase-4)

## Описание

Драйвер сигнальной RGB-LED, подключённой к `BOARD_RGB_LED_GPIO` (GPIO 38). Использует managed-компонент Espressif `led_strip` через RMT. На плате Waveshare ESP32-S3-ETH-8DI-8RO стоит одна WS2812-совместимая LED — этого достаточно для статусной индикации.

Реализует автомат паттернов так же, как `hal_buzzer`: основной цикл `process_task` дёргает `hal_rgb_tick()` каждые 100 мс для воспроизведения мигания, и раз в 5 секунд пересчитывает целевой цвет на основе состояния SM и активных аварий.

**Файлы:**
- Заголовок: `components/board_hal/include/hal_rgb.h`
- Реализация: `components/board_hal/hal_rgb.c`
- Зависимость: `espressif/led_strip ^2.5.0` (см. `main/idf_component.yml`)

## Цветовая логика (приоритет: алармы > состояние SM)

| Условие | Цвет | Мигание |
|---|---|---|
| Активна CRITICAL авария | Красный (255,0,0) | да |
| `SM_FAULT` | Красный | нет |
| `SM_MANUAL` | Фиолетовый (128,0,128) | нет |
| `SM_WASHING` + `WAIT_*` (ожидание оператора) | Оранжевый (255,128,0) | да |
| `SM_WASHING` + активная авария | Жёлтый (255,200,0) | нет |
| `SM_WASHING` (HEATING/SUPPLY/DRAIN/DONE) | Синий (0,0,255) | нет |
| `SM_AUTO` + `AUTO_RUNNING` | Зелёный (0,200,0) | нет |
| `SM_AUTO` + переходы (RAMP, FILLING) | Голубой (0,200,200) | нет |
| `SM_IDLE` + ALARM | Жёлтый | нет |
| `SM_IDLE` + WARNING | Тёплый тусклый (64,48,0) | нет |
| `SM_IDLE` (норма) | Тусклый белый (16,16,16) | нет |

## API

### `esp_err_t hal_rgb_init(void)`
Инициализация RMT-канала + led_strip handle. Soft-fail в `app_main` — ошибка не валит систему.

### `void hal_rgb_set(uint8_t r, uint8_t g, uint8_t b, bool blink)`
Установка цвета. При `blink=true` цвет переключается между заданным и (0,0,0) с периодом 1 Гц. Сравнивает с предыдущим запросом — повторный вызов с теми же параметрами no-op.

### `void hal_rgb_tick(void)`
Один шаг автомата мигания. Вызывать каждые 100 мс из `process_task`. Без блокировки.

### `void hal_rgb_off(void)`
Полное гашение.

## Не реализовано

- **Несколько LED** в гирлянде — `led_strip_config.max_leds = 1` фиксировано. Если нужно больше — параметризовать.
- **Анимации яркости** (fade in/out) — сейчас только on/off мигание.
