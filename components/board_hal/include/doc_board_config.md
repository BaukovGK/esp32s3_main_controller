# board_config.h -- Распиновка и аппаратные константы платы

## Описание файла

Заголовочный файл конфигурации платы **Waveshare ESP32-S3-ETH-8DI-8RO**. Содержит все аппаратные константы: номера GPIO, I2C-адреса, параметры UART, адреса Modbus-устройств, а также логические назначения дискретных входов (DI) и выходов (DO). Является центральным местом определения всей распиновки -- все остальные модули HAL ссылаются на этот файл.

**Путь:** `components/board_hal/include/board_config.h`

---

## Зависимости

Файл не включает никаких других заголовков. Используется директива `#pragma once` для защиты от повторного включения.

---

## Константы и макроопределения (#define)

### Дискретные входы (DI) -- прямые GPIO

Входы используют оптоизоляцию, поэтому логика **инвертирована**: замкнут на GND = логическая 1 (активен).

| Константа | Значение | Описание |
|---|---|---|
| `BOARD_DI1_GPIO` | `4` | Номер GPIO для дискретного входа DI1 |
| `BOARD_DI2_GPIO` | `5` | Номер GPIO для дискретного входа DI2 |
| `BOARD_DI3_GPIO` | `6` | Номер GPIO для дискретного входа DI3 |
| `BOARD_DI4_GPIO` | `7` | Номер GPIO для дискретного входа DI4 |
| `BOARD_DI5_GPIO` | `8` | Номер GPIO для дискретного входа DI5 |
| `BOARD_DI6_GPIO` | `9` | Номер GPIO для дискретного входа DI6 |
| `BOARD_DI7_GPIO` | `10` | Номер GPIO для дискретного входа DI7 |
| `BOARD_DI8_GPIO` | `11` | Номер GPIO для дискретного входа DI8 |
| `BOARD_DI_COUNT` | `8` | Общее количество дискретных входов |

### Релейные выходы (DO) -- через I2C-расширитель TCA9554PWR

Выходы управляются не напрямую через GPIO, а через I2C-расширитель портов TCA9554PWR.

| Константа | Значение | Описание |
|---|---|---|
| `BOARD_TCA9554_ADDR` | `0x20` | 7-битный I2C-адрес микросхемы TCA9554PWR |
| `BOARD_DO_COUNT` | `8` | Общее количество дискретных (релейных) выходов |

### I2C шина

Шина I2C используется для связи с TCA9554 (управление реле) и RTC PCF85063 (часы реального времени).

| Константа | Значение | Описание |
|---|---|---|
| `BOARD_I2C_SDA_GPIO` | `42` | Номер GPIO для линии SDA шины I2C |
| `BOARD_I2C_SCL_GPIO` | `41` | Номер GPIO для линии SCL шины I2C |
| `BOARD_I2C_FREQ_HZ` | `100000` | Частота тактирования I2C (100 кГц, стандартный режим) |
| `BOARD_I2C_PORT` | `0` | Номер порта I2C (соответствует `I2C_NUM_0`) |

### RS-485 UART

Параметры последовательного порта для связи по протоколу RS-485 (Modbus RTU).

| Константа | Значение | Описание |
|---|---|---|
| `BOARD_RS485_TX_GPIO` | `17` | Номер GPIO для линии TX UART |
| `BOARD_RS485_RX_GPIO` | `18` | Номер GPIO для линии RX UART |
| `BOARD_RS485_UART_PORT` | `1` | Номер порта UART (соответствует `UART_NUM_1`) |
| `BOARD_RS485_BAUDRATE` | `115200` | Скорость передачи данных (бод) |
| `BOARD_RS485_RTS_GPIO` | `(-1)` | Номер GPIO для RTS. Значение -1 означает `UART_PIN_NO_CHANGE` -- автоматическое управление направлением передачи |

### Modbus slave-адреса

Адреса подчиненных устройств на шине Modbus RTU.

| Константа | Значение | Описание |
|---|---|---|
| `MB_ADDR_WAVESHARE_AI` | `1` | Modbus-адрес модуля аналоговых входов Waveshare |
| `MB_ADDR_URZH2KM` | `2` | Modbus-адрес устройства УРЖКМ (управление расходом жидкости) |
| `MB_ADDR_SL21_201` | `10` | Modbus-адрес датчика SL21-201 |
| `MB_ADDR_SL21_101` | `11` | Modbus-адрес датчика SL21-101 |

### Назначение дискретных выходов (RO1-RO8)

Логические имена для релейных выходов. Значение -- номер выхода (1..8).

| Константа | Значение | Описание |
|---|---|---|
| `BOARD_DO_PUMP_FEED` | `1` | RO1: реле насоса подачи воды |
| `BOARD_DO_PUMP_STAGE1` | `2` | RO2: реле насоса 1-й ступени (мембранного) |
| `BOARD_DO_PUMP_STAGE2` | `3` | RO3: реле насоса 2-й ступени |
| `BOARD_DO_HEATER` | `4` | RO4: реле нагревательного элемента (ТЭН) |
| `BOARD_DO_DOSER` | `5` | RO5: реле дозатора химических реагентов |

### Назначение дискретных входов (DI1-DI8)

Логические имена для дискретных входов. Значение -- номер входа (1..8). В комментариях указан тип контакта (NC -- нормально замкнутый, NO -- нормально разомкнутый) и логика активации.

| Константа | Значение | Описание |
|---|---|---|
| `BOARD_DI_SOURCE_EMPTY` | `1` | DI1: датчик "источник пуст". Тип NC: 0 = источник пуст (контакт разомкнулся) |
| `BOARD_DI_INTERM_EMPTY` | `2` | DI2: датчик "промежуточный бак пуст". Тип NC: 0 = бак пуст |
| `BOARD_DI_INTERM_FULL` | `3` | DI3: датчик "промежуточный бак полон". Тип NO: 1 = бак полон (контакт замкнулся) |
| `BOARD_DI_PERMEATE_FULL` | `4` | DI4: датчик "бак пермеата полон". Тип NO: 1 = бак полон |
| `BOARD_DI_ESTOP` | `5` | DI5: аварийная кнопка останова (E-STOP). Тип NC: 0 = авария (кнопка нажата / контакт разомкнулся) |
| `BOARD_DI_PUMP1_CONF` | `6` | DI6: сигнал подтверждения работы насоса подачи |
| `BOARD_DI_PUMP2_CONF` | `7` | DI7: сигнал подтверждения работы насоса 1-й ступени |
| `BOARD_DI_PUMP3_CONF` | `8` | DI8: сигнал подтверждения работы насоса 2-й ступени |

### Прочая периферия

| Константа | Значение | Описание |
|---|---|---|
| `BOARD_BUZZER_GPIO` | `46` | Номер GPIO для управления зуммером (пьезоизлучателем) |
| `BOARD_RGB_LED_GPIO` | `38` | Номер GPIO для управления RGB-светодиодом (WS2812 или аналог) |

## Примечания

- Все номера GPIO соответствуют распиновке платы Waveshare ESP32-S3-ETH-8DI-8RO.
- Выходы RO6, RO7, RO8 не имеют логических имён в текущей конфигурации (зарезервированы).
- Входы используют оптоизоляцию, что обеспечивает гальваническую развязку, но требует инвертированной логики при чтении GPIO.
