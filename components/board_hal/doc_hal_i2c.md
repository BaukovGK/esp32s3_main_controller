# hal_i2c.h / hal_i2c.c -- I2C master шина (потокобезопасная обёртка)

## Описание модуля

Модуль аппаратной абстракции для работы с шиной I2C в режиме master. Предоставляет потокобезопасный интерфейс для чтения и записи отдельных байтов в регистры I2C-устройств.

Используется для связи с:
- **TCA9554PWR** (I2C-адрес 0x20) -- расширитель портов для управления релейными выходами DO
- **PCF85063** -- часы реального времени (RTC)

Потокобезопасность обеспечивается внутренним мьютексом FreeRTOS (`SemaphoreHandle_t`), который захватывается перед каждой операцией I2C и освобождается после её завершения. Это позволяет безопасно вызывать функции модуля из разных задач FreeRTOS.

**Файлы:**
- Заголовок: `components/board_hal/include/hal_i2c.h`
- Реализация: `components/board_hal/hal_i2c.c`

## Константы и макроопределения (#define)

| Константа | Значение | Описание |
|---|---|---|
| `I2C_GLITCH_IGNORE_CNT` | `7` | Количество тактов для фильтра помех (glitch filter) на линиях SDA/SCL |
| `I2C_TIMEOUT_MS` | `100` | Таймаут операций I2C (передача/приём) в миллисекундах |

## Функции

### hal_i2c_init

```c
esp_err_t hal_i2c_init(void);
```

**Описание:** Инициализация I2C master шины. Выполняет следующие действия:

1. Создаёт мьютекс FreeRTOS (`xSemaphoreCreateMutex`). При неудаче возвращает `ESP_ERR_NO_MEM`.
2. Заполняет конфигурационную структуру `i2c_master_bus_config_t`:
   - Порт: `BOARD_I2C_PORT` (I2C_NUM_0)
   - SDA: `BOARD_I2C_SDA_GPIO` (GPIO 42)
   - SCL: `BOARD_I2C_SCL_GPIO` (GPIO 41)
   - Источник тактирования: `I2C_CLK_SRC_DEFAULT`
   - Фильтр помех (glitch): `I2C_GLITCH_IGNORE_CNT` (7) тактов
   - Внутренняя подтяжка: включена
3. Вызывает `i2c_new_master_bus()` для создания шины и сохраняет дескриптор в `s_bus_handle`.
4. Выводит информационное сообщение в лог.

**Параметры:** Нет.

**Возвращаемое значение:**
- `ESP_OK` -- успешная инициализация
- `ESP_ERR_NO_MEM` -- не удалось создать мьютекс
- Код ошибки ESP-IDF -- при ошибке инициализации I2C шины

### hal_i2c_write_reg

```c
esp_err_t hal_i2c_write_reg(uint8_t dev_addr, uint8_t reg, uint8_t data);
```

**Описание:** Запись одного байта данных в указанный регистр I2C-устройства. Операция потокобезопасна.

**Алгоритм работы:**
1. Захватывает мьютекс `s_mutex` с бесконечным ожиданием.
2. Создаёт временное устройство на шине через `i2c_master_bus_add_device()` с 7-битным адресом и частотой `BOARD_I2C_FREQ_HZ`.
3. Формирует буфер из 2 байт: `[reg, data]`.
4. Передаёт буфер через `i2c_master_transmit()` с таймаутом `I2C_TIMEOUT_MS` (100 мс).
5. Удаляет устройство с шины через `i2c_master_bus_rm_device()`.
6. Освобождает мьютекс.

**Примечание к реализации:** Устройство добавляется и удаляется при каждом вызове. В комментарии к коду отмечено, что в будущем планируется кэширование дескрипторов устройств.

**Параметры:**

| Параметр | Тип | Описание |
|---|---|---|
| `dev_addr` | `uint8_t` | 7-битный I2C-адрес устройства (например, 0x20 для TCA9554) |
| `reg` | `uint8_t` | Адрес регистра в устройстве, в который записываются данные |
| `data` | `uint8_t` | Байт данных для записи |

**Возвращаемое значение:**
- `ESP_OK` -- успешная запись
- `ESP_FAIL` или другой код ошибки -- при ошибке добавления устройства на шину или ошибке передачи

### hal_i2c_read_reg

```c
esp_err_t hal_i2c_read_reg(uint8_t dev_addr, uint8_t reg, uint8_t *data);
```

**Описание:** Чтение одного байта из указанного регистра I2C-устройства. Операция потокобезопасна.

**Алгоритм работы:**
1. Проверяет указатель `data` на NULL. При NULL возвращает `ESP_ERR_INVALID_ARG`.
2. Захватывает мьютекс `s_mutex` с бесконечным ожиданием.
3. Создаёт временное устройство на шине через `i2c_master_bus_add_device()`.
4. Выполняет операцию "передача-приём" через `i2c_master_transmit_receive()`:
   - Передаёт 1 байт (адрес регистра `reg`)
   - Принимает 1 байт (данные регистра) в `data`
   - Таймаут: `I2C_TIMEOUT_MS` (100 мс)
5. Удаляет устройство с шины.
6. Освобождает мьютекс.

**Параметры:**

| Параметр | Тип | Описание |
|---|---|---|
| `dev_addr` | `uint8_t` | 7-битный I2C-адрес устройства |
| `reg` | `uint8_t` | Адрес регистра в устройстве, из которого читаются данные |
| `data` | `uint8_t *` | [out] Указатель на переменную для записи прочитанного байта. Не должен быть NULL |

**Возвращаемое значение:**
- `ESP_OK` -- успешное чтение
- `ESP_ERR_INVALID_ARG` -- указатель `data` равен NULL
- Код ошибки ESP-IDF -- при ошибке I2C-операции

## Примечания

- Модуль использует **новый I2C master драйвер** ESP-IDF v5.x (`driver/i2c_master.h`), а не устаревший (`driver/i2c.h`).
- Все операции I2C имеют таймаут **`I2C_TIMEOUT_MS` (100 мс)**. Если устройство не отвечает в течение этого времени, функция вернёт ошибку.
- При каждом вызове `hal_i2c_write_reg()` / `hal_i2c_read_reg()` устройство добавляется на шину и затем удаляется. Это упрощает код, но добавляет накладные расходы. Для высокочастотных операций может потребоваться кэширование дескрипторов.
- Мьютекс захватывается с `portMAX_DELAY` (бесконечное ожидание), поэтому вызовы могут блокировать задачу на неопределённое время, если другая задача удерживает мьютекс.
- Фильтр помех (glitch) настроен на `I2C_GLITCH_IGNORE_CNT` (7) тактов тактового сигнала, что помогает отфильтровать кратковременные помехи на линиях SDA/SCL.
- Внутренняя подтяжка (internal pull-up) включена, но для надёжной работы рекомендуются внешние подтягивающие резисторы (обычно уже установлены на плате).
