# hal_uart.h / hal_uart.c -- UART для RS-485 Modbus

## Описание модуля

Минимальный модуль аппаратной абстракции для UART-порта, используемого для связи по RS-485 (протокол Modbus RTU).

Модуль выполняет **только диагностическую функцию**: при инициализации выводит в лог конфигурационные параметры UART (номер порта, пины TX/RX, скорость). Фактическую настройку и управление UART-портом берёт на себя библиотека **esp-modbus**, которая переконфигурирует UART при вызове `mbc_master_setup()`.

Таким образом, `hal_uart_init()` служит для:
- Ранней проверки (на этапе инициализации HAL), что параметры UART определены корректно
- Диагностического логирования конфигурации RS-485
- Единообразия интерфейса инициализации HAL-модулей

**Файлы:**
- Заголовок: `components/board_hal/include/hal_uart.h`
- Реализация: `components/board_hal/hal_uart.c`

| Константа (из board_config.h) | Значение | Использование в модуле |

| `BOARD_RS485_UART_PORT` | `1` | Номер UART-порта (UART_NUM_1) |

## Функции

### hal_uart_init

```c
esp_err_t hal_uart_init(void);
```

**Описание:** Инициализация UART1 для RS-485. В текущей реализации функция **не выполняет фактической аппаратной настройки** UART. Она только выводит в лог информационное сообщение с параметрами конфигурации RS-485:
- Номер UART-порта
- Номера GPIO для TX и RX
- Скорость передачи (бод)
- Формат кадра: 8N1 (8 бит данных, без контроля чётности, 1 стоп-бит)

Это сделано намеренно, так как библиотека esp-modbus сама управляет конфигурацией UART-драйвера при инициализации Modbus master.

**Параметры:** Нет.

**Возвращаемое значение:**
- `ESP_OK` -- всегда возвращает успех (в текущей реализации)

---

## Примечания

- Формат кадра RS-485: **8N1** (8 бит данных, без контроля чётности, 1 стоп-бит) -- стандарт для Modbus RTU.
- Линия RTS не используется (`BOARD_RS485_RTS_GPIO = -1`), направление передачи RS-485 управляется автоматически (вероятно, аппаратно на плате).
- Если в будущем потребуется ранняя инициализация UART (до esp-modbus), функцию `hal_uart_init()` можно дополнить вызовами `uart_driver_install()`, `uart_param_config()` и `uart_set_pin()`.
- Модуль включает заголовок `driver/uart.h`, хотя в текущей реализации не использует функции из него. Это подготовка для возможного расширения функциональности.
