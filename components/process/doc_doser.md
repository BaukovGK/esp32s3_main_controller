# doser.h / doser.c

## Описание модуля

Модуль реализует **таймерное управление дозатором антискаланта** -- химического реагента, предотвращающего образование накипи на мембранах обратного осмоса. Дозатор работает по циклическому принципу: подача реагента в течение `run_time_min` минут, затем пауза, общий период цикла -- `cycle_time_min` минут.

Дозатор активен **только** в автоматическом режиме, когда установка находится в подсостоянии `AUTO_RUNNING` и дозатор включен (enabled). Управляет дискретным выходом RO5 (`BOARD_DO_DOSER`).

**Файлы:**
- `components/process/include/doser.h` -- публичный заголовок (перечисление состояний, API)
- `components/process/doser.c` -- реализация циклического таймера

**Частота вызова:** функция `doser_update()` вызывается каждые 100 мс из `process_task`.

## Перечисления (enum)

### doser_state_t -- Состояния дозатора

| Значение | Описание |
|---|---|
| `DOSER_OFF` | Дозатор выключен. Начальное состояние. Активно когда установка не в `AUTO_RUNNING` или дозатор программно отключен (`s_enabled = false`). |
| `DOSER_RUNNING` | Дозатор работает -- реагент подаётся. RO5 = ON. Длительность -- `run_time_min` минут. |
| `DOSER_PAUSE` | Пауза между подачами реагента. RO5 = OFF. Длительность -- `(cycle_time_min - run_time_min)` минут. |

## Функции

### `void doser_init(void)`

**Сигнатура:**
```c
void doser_init(void);
```

**Описание:** Инициализация модуля дозатора. Сбрасывает состояние, включает программный флаг разрешения, выключает аппаратный выход.

**Параметры:** Нет.

**Возвращаемое значение:** Нет.

**Алгоритм:**
1. `s_state = DOSER_OFF`.
2. `s_enabled = true` -- дозатор включён по умолчанию.
3. `s_timer_start = 0`.
4. Выключает RO5: `hal_gpio_write_do_pin(BOARD_DO_DOSER, false)`.
5. Лог об инициализации.

---

### `void doser_update(bool auto_running)`

**Сигнатура:**
```c
void doser_update(bool auto_running);
```

**Описание:** Основная функция обновления состояния дозатора. Вызывается каждые 100 мс. Реализует циклический таймер: работа -> пауза -> работа -> ...

**Параметры:**

| Параметр | Тип | Описание |
|---|---|---|
| `auto_running` | `bool` | `true` = установка находится в состоянии `SM_AUTO`, подсостояние `AUTO_RUNNING`. Передаётся из `process_task`. |

**Возвращаемое значение:** Нет.

**Алгоритм:**

1. **Условие активности:**
   - Если `auto_running == false` ИЛИ `s_enabled == false`:
     - Если дозатор не в `DOSER_OFF` -- переход в `DOSER_OFF`, сброс таймера, выключение RO5.
     - Немедленный возврат.
2. **Вычисление временных интервалов из конфигурации:**
   - `run_us = run_time_min * 60 * 1000000` -- длительность работы в микросекундах.
   - `cycle_us = cycle_time_min * 60 * 1000000` -- полный период цикла.
   - `pause_us = cycle_us - run_us` -- длительность паузы.
3. **Автомат состояний:**
   - **DOSER_OFF:** Первый запуск. Переход в `DOSER_RUNNING`, запись текущего времени, включение RO5. Лог с указанием длительности работы.
   - **DOSER_RUNNING:** Проверка `(now - s_timer_start) >= run_us`. При истечении -- переход в `DOSER_PAUSE`, сброс таймера, выключение RO5. Лог с указанием длительности паузы.
   - **DOSER_PAUSE:** Проверка `(now - s_timer_start) >= pause_us`. При истечении -- переход в `DOSER_RUNNING`, сброс таймера, включение RO5. Лог с указанием длительности работы.

**Пример с параметрами по умолчанию** (`run_time_min=5`, `cycle_time_min=60`):
- 5 минут работа (RO5 = ON)
- 55 минут пауза (RO5 = OFF)
- 5 минут работа...
- и т.д.

### `void doser_enable(bool en)`

**Сигнатура:**
```c
void doser_enable(bool en);
```

**Описание:** Программное включение/отключение дозатора. При отключении дозатор перейдёт в `DOSER_OFF` на следующем цикле `doser_update`.

**Параметры:**

| Параметр | Тип | Описание |
|---|---|---|
| `en` | `bool` | `true` = включить дозатор, `false` = отключить |

**Возвращаемое значение:** Нет.

---

**Сигнатура:**
```c
bool doser_is_enabled(void);
```

## Диаграмма состояний дозатора

```
                    auto_running=false
                    ИЛИ s_enabled=false
              +---------------------------+
              |                           |
              v                           |
         +---------+                      |
  init-->| OFF     |                      |
         +---------+                      |
              |                           |
              | auto_running=true         |
              | И s_enabled=true          |
              |                           |
              v                           |
         +---------+   run_time_min   +---------+
         | RUNNING |----------------->|  PAUSE  |
         |  RO5=ON |                  |  RO5=OFF|
         +---------+                  +---------+
              ^                           |
              |    (cycle - run) мин      |
              +---------------------------+
```

## Параметры из конфигурации (значения по умолчанию)

| Параметр | Значение | Описание |
|---|---|---|
| `doser.run_time_min` | 5 мин | Время подачи реагента за один цикл |
| `doser.cycle_time_min` | 60 мин | Полный период цикла (работа + пауза) |

**Вычисляемое значение:** пауза = `cycle_time_min - run_time_min` = 55 мин (по умолчанию).
