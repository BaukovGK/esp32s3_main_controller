# interlocks.h / interlocks.c

## Описание модуля

Модуль реализует **систему блокировок безопасности** установки обратного осмоса. Проверяет аварийные условия (кнопка E-STOP, сухой ход, превышение давления, перегрев, засорение фильтра) и формирует разрешения на работу каждого исполнительного механизма.

Вызывается каждые 100 мс из `state_machine_update()`. Результат проверки влияет на фактическое состояние дискретных выходов: желаемое состояние выхода логически умножается (AND) на разрешение из интерлоков.

**Файлы:**
- `components/process/include/interlocks.h` -- публичный заголовок (флаги, структура результата, API)
- `components/process/interlocks.c` -- реализация проверок

## Константы (#define) -- Битовые флаги блокировок

Каждый флаг представляет собой бит в 32-битной маске `active_flags` структуры `interlock_result_t` и в `fault_flags` конечного автомата.

| Константа | Значение | Описание |
|---|---|---|
| `INTERLOCK_ESTOP` | `(1 << 0)` = `0x0001` | Аварийная кнопка E-STOP активна. DI5 = 0 (нормально замкнутый контакт NC, активен при размыкании). Блокирует **все** выходы. |
| `INTERLOCK_SOURCE_EMPTY` | `(1 << 1)` = `0x0002` | Источник воды пуст. DI1 = 0 (NC-контакт). Блокирует: насос подачи (`pump_feed`), насос 1-й ступени (`pump_stage1`). Защита от сухого хода. |
| `INTERLOCK_INTERM_EMPTY` | `(1 << 2)` = `0x0004` | Промежуточный бак пуст. DI2 = 0 (NC-контакт). Блокирует: насос 2-й ступени (`pump_stage2`). Защита от сухого хода. |
| `INTERLOCK_P1_HIGH` | `(1 << 3)` = `0x0008` | Давление P1 превышает порог `p1_max` (по умолчанию 5.5 бар). Блокирует: насос подачи (`pump_feed`). |
| `INTERLOCK_P3_HIGH` | `(1 << 4)` = `0x0010` | Давление P3 превышает порог `p3_max` (по умолчанию 35.0 бар). Блокирует: насос 1-й ступени (`pump_stage1`). |
| `INTERLOCK_P4_HIGH` | `(1 << 5)` = `0x0020` | Давление P4 превышает порог `p4_max` (по умолчанию 8.0 бар). Блокирует: насос 2-й ступени (`pump_stage2`). |
| `INTERLOCK_T_HIGH` | `(1 << 6)` = `0x0040` | Температура превышает аварийный порог `t_overshoot_C` (по умолчанию 45.0 C). Блокирует: ТЭН (`heater`). Также используется в `state_machine.c` при перегреве во время промывки. |
| `INTERLOCK_FILTER_DP` | `(1 << 7)` = `0x0080` | Перепад давления на фильтре (P1 - P2) превышает порог `filter_dp_warn` (по умолчанию 1.0 бар). **Только предупреждение**, не блокирует ни один выход. Устанавливает `filter_warn = true`. |
| `INTERLOCK_PUMP1_TIMEOUT` | `(1 << 8)` = `0x0100` | Таймаут подтверждения насоса подачи (DI6 не появился в течение `pump_confirm_ms`). Используется в `state_machine.c`, а не в `interlocks.c`. |
| `INTERLOCK_PUMP2_TIMEOUT` | `(1 << 9)` = `0x0200` | Таймаут подтверждения насоса 1-й ступени (DI7). Аналогично. |
| `INTERLOCK_PUMP3_TIMEOUT` | `(1 << 10)` = `0x0400` | Таймаут подтверждения насоса 2-й ступени (DI8). Аналогично. |
| `INTERLOCK_SENSOR_FAULT_P1` | `(1 << 11)` = `0x0800` | **Phase-1**: датчик P1 неисправен (NaN от `analog_input` — обрыв 4–20 мА (raw < 3500 мкА), КЗ (raw > 20500 мкА) или offline Modbus). Блокирует: `pump_feed`. |
| `INTERLOCK_SENSOR_FAULT_P3` | `(1 << 12)` = `0x1000` | **Phase-1**: датчик P3 неисправен. Блокирует: `pump_stage1`. |
| `INTERLOCK_SENSOR_FAULT_P4` | `(1 << 13)` = `0x2000` | **Phase-1**: датчик P4 неисправен. Блокирует: `pump_stage2`. |
| `INTERLOCK_SENSOR_FAULT_T` | `(1 << 14)` = `0x4000` | **Phase-1**: датчик температуры неисправен. Блокирует: `heater`. |
| `INTERLOCK_UNEXPECTED_RESTART` | `(1 << 15)` = `0x8000` | **Phase-2**: после неожиданной перезагрузки (panic / WDT / brownout) во время AUTO или WASHING. Поднимается `state_machine_init()`. Снимается только `CMD_RESET_FAULT` от оператора — система отказывается слепо продолжать работу с неизвестным состоянием агрегатов. |
| `INTERLOCK_STEP_TIMEOUT` | `(1 << 16)` = `0x10000` | **Phase-4 (H-step-timeout)**: подсостояние AUTO (STARTING_PUMP1/2/3, FILLING_INTERM) не завершилось за `config.timeouts.step_timeout_s`. Поднимается из `update_auto`, сопровождается `ALARM_STEP_TIMEOUT`. |
| `INTERLOCK_KNOWN_MASK`   | OR всех бит выше | **Phase-4 (C-3)**: маска для валидации `fault_flags` при восстановлении из NVS. «Лишние» биты вне маски трактуются как повреждение NVS — данные отбрасываются, поднимается `ALARM_UNEXPECTED_RESTART`. |

## Структуры (struct)

### interlock_result_t -- Результат проверки блокировок

| Поле | Тип | Описание |
|---|---|---|
| `active_flags` | `uint32_t` | Битовая маска всех активных блокировок (комбинация `INTERLOCK_*` флагов). Значение 0 означает отсутствие блокировок. |
| `allow_pump_feed` | `bool` | Разрешение на работу насоса подачи (pump1, RO1). `false` при: E-STOP, источник пуст, P1 > max. |
| `allow_pump_stage1` | `bool` | Разрешение на работу насоса 1-й ступени (pump2, RO2). `false` при: E-STOP, источник пуст, P3 > max. |
| `allow_pump_stage2` | `bool` | Разрешение на работу насоса 2-й ступени (pump3, RO3). `false` при: E-STOP, промбак пуст, P4 > max. |
| `allow_heater` | `bool` | Разрешение на работу ТЭНа (RO4). `false` при: E-STOP, T > t_overshoot. |
| `allow_doser` | `bool` | Разрешение на работу дозатора (RO5). `false` при: E-STOP. |
| `estop_active` | `bool` | Признак активности аварийной кнопки E-STOP. Используется в `state_machine_update` для перехода в `SM_FAULT`. |
| `filter_warn` | `bool` | Признак предупреждения о засорении фильтра (перепад давления P1-P2 > порога). Только информационный, не блокирует работу. |

void interlocks_init(void);

### `void interlocks_check(bool manual_mode, interlock_result_t *result)`

**Сигнатура:**
```c
void interlocks_check(bool manual_mode, interlock_result_t *result);
```

**Описание:** Основная функция проверки всех блокировок безопасности. Читает дискретные входы и аналоговые значения, сравнивает с порогами из конфигурации и формирует результат.

**Параметры:**

| Параметр | Тип | Описание |
|---|---|---|
| `manual_mode` | `bool` | `true` = установка в ручном режиме (`SM_MANUAL`). В этом случае проверяется **только E-STOP**, все остальные блокировки пропускаются. |
| `result` | `interlock_result_t *` | Выходной параметр -- результат проверки. Заполняется функцией. |

**Возвращаемое значение:** Нет (результат через выходной параметр).

**Алгоритм:**

1. **Инициализация результата:**
   - `active_flags = 0`
   - Все `allow_*` = `true`
   - `estop_active = false`
   - `filter_warn = false`

2. **Проверка E-STOP (DI5):**
   - E-STOP -- нормально замкнутый контакт (NC). Активен когда DI5 = 0 (разомкнут).
   - Логика чтения: `estop = !(di & (1 << (BOARD_DI_ESTOP - 1)))`, т.е. `!(di & 0x10)`.
   - При активном E-STOP:
     - Устанавливается флаг `INTERLOCK_ESTOP`.
     - `estop_active = true`.
     - **Все** разрешения (`allow_*`) = `false`.
     - **Немедленный возврат** -- дальнейшие проверки не выполняются.

3. **Проверка ручного режима:**
   - Если `manual_mode == true` -- немедленный возврат. В ручном режиме оператор несёт полную ответственность, блокировки (кроме E-STOP) не действуют.

4. **Проверка дискретных входов -- сухой ход:**
   - **DI1 -- источник пуст** (NC: 0 = пуст): `source_empty = !(di & (1 << 0))`.
     - При пустом источнике: флаг `INTERLOCK_SOURCE_EMPTY`, запрет `allow_pump_feed` и `allow_pump_stage1`.
   - **DI2 -- промбак пуст** (NC: 0 = пуст): `interm_empty = !(di & (1 << 1))`.
     - При пустом промбаке: флаг `INTERLOCK_INTERM_EMPTY`, запрет `allow_pump_stage2`.

5. **Проверка давлений (аналоговые входы):**
   - Чтение P1, P2, P3, P4 через `analog_input_get_value()`.
   - **Phase-1 (отказоустойчивость):** NaN теперь трактуется как **отказ датчика** и блокирует
     соответствующий агрегат (без блокировки система продолжала бы работать без верхней защиты по давлению).
     NaN возвращается из `analog_input` при любом из условий неисправности 4–20 мА:
     - **обрыв линии:** `raw < FAULT_BREAK_UA` (3500 мкА, ~3.5 мА);
     - **короткое замыкание:** `raw > FAULT_SHORT_UA` (20500 мкА, ~20.5 мА);
     - **offline Modbus** (slave не отвечает).

     Действия:
     - `isnan(P1)`: флаг `INTERLOCK_SENSOR_FAULT_P1`, запрет `allow_pump_feed`.
     - `isnan(P3)`: флаг `INTERLOCK_SENSOR_FAULT_P3`, запрет `allow_pump_stage1`.
     - `isnan(P4)`: флаг `INTERLOCK_SENSOR_FAULT_P4`, запрет `allow_pump_stage2`.
   - При валидном значении проверяется превышение порога:
     - **P1 > p1_max:** флаг `INTERLOCK_P1_HIGH`, запрет `allow_pump_feed`.
     - **P3 > p3_max:** флаг `INTERLOCK_P3_HIGH`, запрет `allow_pump_stage1`.
     - **P4 > p4_max:** флаг `INTERLOCK_P4_HIGH`, запрет `allow_pump_stage2`.

6. **Проверка температуры:**
   - **isnan(T):** флаг `INTERLOCK_SENSOR_FAULT_T`, запрет `allow_heater` (Phase-1; включает обрыв, КЗ и offline Modbus — те же условия, что и для датчиков давления).
   - **T > t_overshoot_C:** флаг `INTERLOCK_T_HIGH`, запрет `allow_heater`.

7. **Проверка перепада давления на фильтре:**
   - Оба P1 и P2 должны быть валидными (не NaN).
   - **(P1 - P2) > filter_dp_warn:** флаг `INTERLOCK_FILTER_DP`, `filter_warn = true`.
   - **Только предупреждение** -- ни один выход не блокируется.

## Матрица блокировок

Таблица показывает, какие условия блокируют какие выходы:

| Условие | pump_feed | pump_stage1 | pump_stage2 | heater | doser |
|---|---|---|---|---|---|
| E-STOP (DI5=0) | БЛОК | БЛОК | БЛОК | БЛОК | БЛОК |
| Источник пуст (DI1=0) | БЛОК | БЛОК | - | - | - |
| Промбак пуст (DI2=0) | - | - | БЛОК | - | - |
| P1 > p1_max | БЛОК | - | - | - | - |
| P3 > p3_max | - | БЛОК | - | - | - |
| P4 > p4_max | - | - | БЛОК | - | - |
| T > t_overshoot | - | - | - | БЛОК | - |
| dP фильтра > порога | - | - | - | - | - |
| **isnan(P1)** *(Phase-1)* | **БЛОК** | - | - | - | - |
| **isnan(P3)** *(Phase-1)* | - | **БЛОК** | - | - | - |
| **isnan(P4)** *(Phase-1)* | - | - | **БЛОК** | - | - |
| **isnan(T)** *(Phase-1)* | - | - | - | **БЛОК** | - |

**Примечание:** В ручном режиме (`manual_mode = true`) действует **только** E-STOP. Все остальные проверки пропускаются.

## Таблица DI-входов и их логика

| DI | GPIO | Назначение | Тип контакта | Активное состояние | Действие при активации |
|---|---|---|---|---|---|
| DI1 | 4 | Источник пуст | NC | 0 (разомкнут) | Стоп pump_feed, pump_stage1 |
| DI2 | 5 | Промбак пуст | NC | 0 (разомкнут) | Стоп pump_stage2 |
| DI3 | 6 | Промбак полон | NO | 1 (замкнут) | (Обрабатывается в state_machine) |
| DI4 | 7 | Бак пермеата полон | NO | 1 (замкнут) | (Обрабатывается в state_machine) |
| DI5 | 8 | E-STOP | NC | 0 (разомкнут) | Блокировка ВСЕХ выходов |
| DI6 | 9 | Подтверждение pump1 | NO | 1 (замкнут) | (Обрабатывается в state_machine) |
| DI7 | 10 | Подтверждение pump2 | NO | 1 (замкнут) | (Обрабатывается в state_machine) |
| DI8 | 11 | Подтверждение pump3 | NO | 1 (замкнут) | (Обрабатывается в state_machine) |

**NC** (Normally Closed) -- нормально замкнут. При нормальной работе DI = 1 (оптоизолятор запитан). При срабатывании (размыкание контакта) DI = 0.

**NO** (Normally Open) -- нормально разомкнут. При срабатывании (замыкание) DI = 1.
