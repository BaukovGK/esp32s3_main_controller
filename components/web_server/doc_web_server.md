# web_server.h / web_server.c — HTTP-сервер контроллера обратного осмоса

## Описание файла

Модуль `web_server` является точкой входа для HTTP-сервера контроллера обратного осмоса. Он отвечает за:

- Создание и настройку экземпляра HTTP-сервера ESP-IDF (`esp_http_server`)
- Регистрацию всех URI-обработчиков (статические файлы, REST API статусов, REST API команд)
- Остановку HTTP-сервера при необходимости

Модуль выступает как координатор: сам не содержит обработчиков запросов, а делегирует регистрацию обработчиков трём вспомогательным модулям: `web_static`, `web_api_status`, `web_api_command`.

**Заголовочный файл:** `components/web_server/include/web_server.h`
**Файл реализации:** `components/web_server/web_server.c`

## Функции

### `esp_err_t web_server_start(void)`

**Объявлена в:** `web_server.h`
**Реализована в:** `web_server.c`

**Параметры:** нет

**Возвращаемое значение:**
- `ESP_OK` — HTTP-сервер успешно запущен и все обработчики зарегистрированы
- Код ошибки ESP-IDF — если `httpd_start()` завершился неудачно

**Описание:**

Функция выполняет полную инициализацию HTTP-сервера:

1. **Создание конфигурации:** Инициализирует структуру `httpd_config_t` значениями по умолчанию (`HTTPD_DEFAULT_CONFIG()`), затем переопределяет:
   - `max_uri_handlers = WEB_MAX_URI_HANDLERS` (20) — максимальное количество зарегистрированных URI-обработчиков (используется ~15, остальное — запас)
   - `stack_size = WEB_STACK_SIZE` (6144) — размер стека серверной задачи увеличен с дефолтного значения для корректной работы с библиотекой cJSON
   - `lru_purge_enable = true` — включает автоматическое закрытие наименее используемых соединений при нехватке сокетов

2. **Запуск сервера:** Вызывает `httpd_start(&s_server, &config)`. В случае ошибки логирует её и возвращает код ошибки.

3. **Регистрация обработчиков:** Последовательно вызывает три функции регистрации:
   - `web_static_register(s_server)` — статические файлы
   - `web_api_register_status(s_server)` — GET API
   - `web_api_register_commands(s_server)` — POST API

4. **Логирование:** Выводит сообщение о запуске сервера с указанием порта (по умолчанию 80).

---

### `void web_server_stop(void)`

**Объявлена в:** `web_server.h`
**Реализована в:** `web_server.c`

**Параметры:** нет

**Возвращаемое значение:** нет (`void`)

**Описание:**

Останавливает HTTP-сервер, если он был запущен:

1. Проверяет, что `s_server` не равен `NULL` (сервер был запущен).
2. Вызывает `httpd_stop(s_server)` для остановки сервера и освобождения ресурсов.
3. Сбрасывает `s_server = NULL`.
4. Логирует сообщение об остановке.

Если сервер не был запущен (или уже остановлен), функция ничего не делает.

---

## Архитектурные замечания

- HTTP-сервер по умолчанию слушает порт **80** (определяется `HTTPD_DEFAULT_CONFIG()`).
- Модуль является синглтоном — одновременно может работать только один экземпляр сервера, хранимый в статической переменной `s_server`.
- Все URI-обработчики регистрируются при старте и не могут быть добавлены или удалены динамически без перезапуска сервера.
