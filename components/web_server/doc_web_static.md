# web_static.c — Раздача встроенных статических файлов (HTML, CSS, JS)

## Описание файла

Модуль `web_static` отвечает за раздачу встроенных (embedded) статических файлов веб-интерфейса контроллера обратного осмоса. Файлы HTML, CSS и JS встраиваются в прошивку на этапе сборки с помощью механизма `EMBED_TXTFILES` ESP-IDF и раздаются HTTP-сервером при обращении к соответствующим URI.

Модуль не имеет собственного заголовочного файла — его единственная публичная функция `web_static_register()` объявлена как forward-declaration в `web_server.c`.

**Файл реализации:** `components/web_server/web_static.c`

## Внешние символы встроенных файлов

Файлы встраиваются в прошивку через механизм `EMBED_TXTFILES` (директива CMake). Для доступа к ним используются внешние символы, генерируемые линковщиком:

| Символ | Asm-имя | Описание |
|--------|---------|----------|
| `index_html_start` | `_binary_index_html_start` | Начало встроенного файла `index.html` |
| `index_html_end` | `_binary_index_html_end` | Конец встроенного файла `index.html` |
| `style_css_start` | `_binary_style_css_start` | Начало встроенного файла `style.css` |
| `style_css_end` | `_binary_style_css_end` | Конец встроенного файла `style.css` |
| `app_js_start` | `_binary_app_js_start` | Начало встроенного файла `app.js` |
| `app_js_end` | `_binary_app_js_end` | Конец встроенного файла `app.js` |

Размер каждого файла вычисляется как разность указателей `end - start`.

## Функции

### `static esp_err_t index_html_handler(httpd_req_t *req)`

**Область видимости:** внутренняя (static)

**Параметры:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `req` | `httpd_req_t *` | Указатель на структуру HTTP-запроса ESP-IDF |

**Возвращаемое значение:**
- `ESP_OK` — ответ успешно отправлен
- Код ошибки ESP-IDF — в случае неудачи отправки

**Описание:**

Обработчик HTTP GET-запроса для корневого URI `/`. Выполняет следующие действия:

1. Устанавливает MIME-тип ответа: `text/html; charset=utf-8`
2. Устанавливает заголовок `Cache-Control: no-cache` для предотвращения кэширования в браузере
3. Отправляет содержимое встроенного файла `index.html` клиенту, используя указатели `index_html_start` и `index_html_end` для определения данных и их длины

### `void web_static_register(httpd_handle_t server)`

**Область видимости:** публичная (вызывается из `web_server.c`)

**Параметры:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `server` | `httpd_handle_t` | Дескриптор запущенного HTTP-сервера, в который регистрируются URI-обработчики |

**Возвращаемое значение:** нет (`void`)

**Описание:**

Регистрирует три URI-обработчика для раздачи статических файлов веб-интерфейса:

| URI | Метод | Обработчик | Файл |
|-----|-------|------------|------|
| `/` | GET | `index_html_handler` | `index.html` |
| `/style.css` | GET | `style_css_handler` | `style.css` |
| `/app.js` | GET | `app_js_handler` | `app.js` |

Для каждого URI создаётся локальная `static const` структура `httpd_uri_t`, которая затем передаётся в `httpd_register_uri_handler()`.

## Архитектурные замечания

- Все файлы отдаются с заголовком `Cache-Control: no-cache`, что удобно при разработке, но может увеличить нагрузку на устройство в продакшене, так как браузер будет запрашивать файлы при каждом обращении.
- Файлы встраиваются в прошивку целиком — для ESP32 с ограниченной flash-памятью важно контролировать размер HTML/CSS/JS.
- Механизм `EMBED_TXTFILES` автоматически добавляет нулевой терминатор, однако в данном коде длина вычисляется через разность указателей, что корректно.
