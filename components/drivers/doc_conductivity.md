# Документация: conductivity (Драйвер кондуктометров)

**Файлы:**
- Заголовочный: `include/conductivity.h`
- Реализация: `conductivity.c`

---

## Общее описание

Драйвер кондуктометров **СЛ21** (измерители удельной электропроводности жидкости). В системе используются два физических прибора СЛ21, каждый из которых может иметь несколько каналов:

- **Прибор с Modbus-адресом 10** — два канала:
  - Канал 1 (sigma1): электропроводность исходной воды
  - Канал 2 (sigma2): электропроводность пермеата 1-й ступени обратного осмоса
- **Прибор с Modbus-адресом 11** — один канал:
  - Канал 1 (sigma3): электропроводность пермеата 2-й ступени обратного осмоса

Каждый канал предоставляет два параметра:
1. **Удельная электропроводность** в микросименс на сантиметр (мкСм/см, uS/cm) — основной параметр качества воды.
2. **Температура** в градусах Цельсия (°C) — используется для температурной компенсации измерений.

Формат данных Modbus:
- Электропроводность: передаётся в двух 16-битных регистрах как uint32 (hi, lo). Для получения значения в мкСм/см: `uint32(hi, lo) / SL21_COND_DIVISOR`.
- Температура: передаётся в одном 16-битном регистре как int16. Для получения значения в °C: `int16 / SL21_TEMP_DIVISOR`.

Драйвер выполняет следующие задачи:
1. Получение сырых Modbus-регистров от двух приборов СЛ21 через модуль `modbus_poller`.
2. Конвертация raw-данных в инженерные единицы (мкСм/см, °C).
3. Контроль онлайн-статуса каждого из двух приборов независимо.
4. Установка флагов валидности для каждого канала.

Используется в системе обратного осмоса для мониторинга качества воды: чем ниже электропроводность, тем лучше очищена вода.

## Константы и макроопределения (#define)

### Публичные (conductivity.h)

| Константа | Значение | Описание |
|-----------|----------|----------|
| `COND_CHANNEL_COUNT` | `3` | Общее количество каналов электропроводности в системе. Три канала распределены между двумя физическими приборами СЛ21: два канала на приборе с адресом 10 и один канал на приборе с адресом 11. |
| `COND_CH_FEED` | `0` | Индекс канала sigma1 — удельная электропроводность исходной (входной) воды. Прибор СЛ21 с Modbus-адресом 10, канал 1. Характеризует качество воды, поступающей на систему обратного осмоса. |
| `COND_CH_PERM1` | `1` | Индекс канала sigma2 — удельная электропроводность пермеата 1-й ступени обратного осмоса. Прибор СЛ21 с Modbus-адресом 10, канал 2. Характеризует качество воды после первой ступени мембранной очистки. |
| `COND_CH_PERM2` | `2` | Индекс канала sigma3 — удельная электропроводность пермеата 2-й ступени обратного осмоса. Прибор СЛ21 с Modbus-адресом 11, канал 1. Характеризует качество воды после второй (финальной) ступени мембранной очистки. |

### Приватные (conductivity.c)

| Константа | Значение | Описание |
|-----------|----------|----------|
| `SL21_COND_DIVISOR` | `100.0f` | Делитель для преобразования сырого 32-битного значения электропроводности в мкСм/см: `raw / SL21_COND_DIVISOR`. |
| `SL21_TEMP_DIVISOR` | `10.0f` | Делитель для преобразования сырого 16-битного значения температуры в °C: `raw / SL21_TEMP_DIVISOR`. |
| `SL21_REG_COND_HI` | `0` | Смещение регистра старшего слова электропроводности внутри блока канала. |
| `SL21_REG_COND_LO` | `1` | Смещение регистра младшего слова электропроводности внутри блока канала. |
| `SL21_REG_TEMP` | `2` | Смещение регистра температуры внутри блока канала. |
| `SL21_CH_STRIDE` | `3` | Количество регистров на один канал прибора СЛ21. Используется для вычисления смещения к данным следующего канала: `base + N * SL21_CH_STRIDE + SL21_REG_*`. |

## Типы данных (typedef / struct)

### Публичные (conductivity.h)

#### `conductivity_data_t`
Агрегированная структура данных кондуктометров. Содержит измеренные значения электропроводности и температуры для всех трёх каналов, а также статус каждого из двух приборов.

| Поле | Тип | Описание |
|------|-----|----------|
| `conductivity_uS` | `float[COND_CHANNEL_COUNT]` | Массив значений удельной электропроводности в микросименс на сантиметр (мкСм/см). Индексация: `[0]` = sigma1 (исходная вода), `[1]` = sigma2 (пермеат 1-й ступени), `[2]` = sigma3 (пермеат 2-й ступени). Вычисляется из двух Modbus-регистров: `uint32(hi, lo) / SL21_COND_DIVISOR`. Типичные значения: исходная вода 200-1000 мкСм/см, пермеат 1-й ступени 5-50 мкСм/см, пермеат 2-й ступени 1-10 мкСм/см. |
| `temperature_C` | `float[COND_CHANNEL_COUNT]` | Массив значений температуры в градусах Цельсия (°C). Индексация аналогична `conductivity_uS`. Вычисляется из одного Modbus-регистра: `int16 / SL21_TEMP_DIVISOR`. Используется для температурной компенсации показаний электропроводности. |
| `channel_ok` | `bool[COND_CHANNEL_COUNT]` | Массив флагов валидности данных для каждого канала. `true` означает, что соответствующий прибор СЛ21 онлайн. Каналы 0 и 1 зависят от статуса прибора с адресом 10 (`device10_online`), канал 2 — от прибора с адресом 11 (`device11_online`). |
| `device10_online` | `bool` | Флаг доступности прибора СЛ21 с Modbus-адресом 10 (обслуживает каналы sigma1 и sigma2). `true` означает, что прибор отвечает на запросы. Определяется функцией `modbus_poller_is_device_online(MB_ADDR_SL21_201)`. |
| `device11_online` | `bool` | Флаг доступности прибора СЛ21 с Modbus-адресом 11 (обслуживает канал sigma3). `true` означает, что прибор отвечает на запросы. Определяется функцией `modbus_poller_is_device_online(MB_ADDR_SL21_101)`. |

## Функции

### `static uint32_t regs_to_uint32(uint16_t hi, uint16_t lo)` (внутренняя)

**Объявление:** `conductivity.c`, строка 21 (статическая функция, не экспортируется)

**Описание:**
Вспомогательная функция для объединения двух 16-битных Modbus-регистров в одно 32-битное беззнаковое целое. Старшее слово помещается в старшие 16 бит, младшее — в младшие 16 бит.

Формула: `result = (hi << 16) | lo`

Используется для восстановления 32-битного значения электропроводности из двух последовательных Modbus-регистров прибора СЛ21.

**Параметры:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `hi` | `uint16_t` | Старшее 16-битное слово (high word). Первый регистр пары. |
| `lo` | `uint16_t` | Младшее 16-битное слово (low word). Второй регистр пары. |

**Возвращаемое значение:**

| Тип | Описание |
|-----|----------|
| `uint32_t` | 32-битное беззнаковое целое, собранное из двух 16-битных регистров. |

### `void conductivity_init(void)`

**Объявление:** `conductivity.h`, строка 33

**Описание:**
Инициализация драйвера кондуктометров. Должна быть вызвана один раз при старте системы перед использованием любых других функций модуля.

Выполняемые действия:
1. Обнуление всей структуры данных `s_data` с помощью `memset()`. Все значения электропроводности и температуры устанавливаются в 0.0, все флаги — в `false`.
2. Вывод информационного сообщения в лог: "Драйвер кондуктометров СЛ21 инициализирован".

**Параметры:** нет

**Возвращаемое значение:** нет (`void`)

### `void conductivity_update(void)`

**Объявление:** `conductivity.h`, строка 34

**Описание:**
Цикл обновления данных кондуктометров. Должна вызываться периодически (например, из основного цикла опроса). При каждом вызове выполняет:

1. **Получение сырых данных от прибора с адресом 10:** вызывает `modbus_poller_get_cond10_raw()` для получения массива из `CID_COND10_REG_COUNT` (6) Modbus-регистров. Каждый канал занимает `SL21_CH_STRIDE` (3) регистра. Формат данных:
   - `c10[SL21_REG_COND_HI]` — старшее слово sigma1 (электропроводность исходной воды)
   - `c10[SL21_REG_COND_LO]` — младшее слово sigma1
   - `c10[SL21_REG_TEMP]` — температура T1 (int16, *10)
   - `c10[SL21_CH_STRIDE + SL21_REG_COND_HI]` — старшее слово sigma2 (электропроводность пермеата 1-й ступени)
   - `c10[SL21_CH_STRIDE + SL21_REG_COND_LO]` — младшее слово sigma2
   - `c10[SL21_CH_STRIDE + SL21_REG_TEMP]` — температура T2 (int16, *10)

2. **Получение сырых данных от прибора с адресом 11:** вызывает `modbus_poller_get_cond11_raw()` для получения массива из `CID_COND11_REG_COUNT` (3) Modbus-регистров. Один канал — `SL21_CH_STRIDE` (3) регистра. Формат данных:
   - `c11[SL21_REG_COND_HI]` — старшее слово sigma3 (электропроводность пермеата 2-й ступени)
   - `c11[SL21_REG_COND_LO]` — младшее слово sigma3
   - `c11[SL21_REG_TEMP]` — температура T3 (int16, *10)

3. **Проверка онлайн-статусов:**
   - `device10_online` = `modbus_poller_is_device_online(MB_ADDR_SL21_201)` — прибор с адресом 10
   - `device11_online` = `modbus_poller_is_device_online(MB_ADDR_SL21_101)` — прибор с адресом 11

4. **Обработка канала sigma1 (COND_CH_FEED):**
   - Электропроводность: `uint32(c10[SL21_REG_COND_HI], c10[SL21_REG_COND_LO]) / SL21_COND_DIVISOR` — мкСм/см
   - Температура: `(int16_t)c10[SL21_REG_TEMP] / SL21_TEMP_DIVISOR` — °C
   - Валидность: `channel_ok = device10_online`

5. **Обработка канала sigma2 (COND_CH_PERM1):**
   - Электропроводность: `uint32(c10[SL21_CH_STRIDE + SL21_REG_COND_HI], c10[SL21_CH_STRIDE + SL21_REG_COND_LO]) / SL21_COND_DIVISOR` — мкСм/см
   - Температура: `(int16_t)c10[SL21_CH_STRIDE + SL21_REG_TEMP] / SL21_TEMP_DIVISOR` — °C
   - Валидность: `channel_ok = device10_online`

6. **Обработка канала sigma3 (COND_CH_PERM2):**
   - Электропроводность: `uint32(c11[SL21_REG_COND_HI], c11[SL21_REG_COND_LO]) / SL21_COND_DIVISOR` — мкСм/см
   - Температура: `(int16_t)c11[SL21_REG_TEMP] / SL21_TEMP_DIVISOR` — °C
   - Валидность: `channel_ok = device11_online`

**Параметры:** нет

**Возвращаемое значение:** нет (`void`)

## Алгоритм работы

### Формат данных СЛ21

Прибор СЛ21 передаёт данные электропроводности и температуры в Modbus-регистрах:

**Электропроводность (2 регистра на значение):**
- Первый регистр (смещение `SL21_REG_COND_HI`) — старшее 16-битное слово (high word)
- Второй регистр (смещение `SL21_REG_COND_LO`) — младшее 16-битное слово (low word)
- Результат: `uint32(hi, lo) / SL21_COND_DIVISOR` дает значение в мкСм/см

**Температура (1 регистр на значение):**
- Один регистр (смещение `SL21_REG_TEMP`) содержит знаковое 16-битное целое (int16)
- Результат: `int16 / SL21_TEMP_DIVISOR` дает значение в °C

### Раскладка регистров

Каждый канал прибора СЛ21 занимает `SL21_CH_STRIDE` (3) последовательных регистра. Смещения внутри блока канала задаются константами `SL21_REG_COND_HI`, `SL21_REG_COND_LO` и `SL21_REG_TEMP`. Для доступа к N-му каналу (нумерация с 0) используется формула: `base[N * SL21_CH_STRIDE + SL21_REG_*]`.

**Прибор с адресом 10 (6 регистров, 2 канала):**

| Индекс | Константа смещения | Содержимое | Формат |
|--------|-------------------|-----------|--------|
| 0 | `0 * SL21_CH_STRIDE + SL21_REG_COND_HI` | sigma1 high word | uint16 (старшее слово электропроводности исходной воды) |
| 1 | `0 * SL21_CH_STRIDE + SL21_REG_COND_LO` | sigma1 low word | uint16 (младшее слово электропроводности исходной воды) |
| 2 | `0 * SL21_CH_STRIDE + SL21_REG_TEMP` | T1 (температура) | int16 (* 10, °C) |
| 3 | `1 * SL21_CH_STRIDE + SL21_REG_COND_HI` | sigma2 high word | uint16 (старшее слово электропроводности пермеата 1-й ступени) |
| 4 | `1 * SL21_CH_STRIDE + SL21_REG_COND_LO` | sigma2 low word | uint16 (младшее слово электропроводности пермеата 1-й ступени) |
| 5 | `1 * SL21_CH_STRIDE + SL21_REG_TEMP` | T2 (температура) | int16 (* 10, °C) |

**Прибор с адресом 11 (3 регистра, 1 канал):**

| Индекс | Константа смещения | Содержимое | Формат |
|--------|-------------------|-----------|--------|
| 0 | `SL21_REG_COND_HI` | sigma3 high word | uint16 (старшее слово электропроводности пермеата 2-й ступени) |
| 1 | `SL21_REG_COND_LO` | sigma3 low word | uint16 (младшее слово электропроводности пермеата 2-й ступени) |
| 2 | `SL21_REG_TEMP` | T3 (температура) | int16 (* 10, °C) |

### Валидация данных
Валидность каналов определяется исключительно доступностью соответствующего прибора на шине Modbus:
- Каналы sigma1 и sigma2 (индексы 0, 1): валидны, если `device10_online == true`
- Канал sigma3 (индекс 2): валиден, если `device11_online == true`

Дополнительная проверка значений на конечность/диапазон не выполняется (в отличие от драйвера расходомера).
