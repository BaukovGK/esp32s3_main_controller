# Документация: flowmeter (Драйвер расходомера)

**Файлы:**
- Заголовочный: `include/flowmeter.h`
- Реализация: `flowmeter.c`

---

## Общее описание

Драйвер расходомера **УРЖ2КМ** (ультразвуковой расходомер жидкости). Прибор подключён по интерфейсу Modbus RTU и передаёт данные о мгновенном расходе (Q1-Q4) и накопленном объёме (V1-V4) по четырём каналам.

> **Важно:** регистры объёмов V5..V8 пока не сверены с протоколом производителя ТЕСС, поэтому до сверки **игнорируются**. Соответственно `CID_FLOW_VOL_REG_COUNT` уменьшен с 16 до 8 регистров (диапазон Modbus сокращён с 0x0036..0x0045 до 0x0036..0x003D), читаются только V1..V4. Каналы расхода Q1..Q4 (8 регистров) — без изменений.

Ключевая особенность: расходомер УРЖ2КМ использует **нестандартный формат представления чисел с плавающей запятой** (word-swapped IEEE 754). В двух 16-битных Modbus-регистрах слова расположены в обратном порядке:
- `reg[0]` = младшее слово (low word) — байты B, C по стандарту IEEE 754
- `reg[1]` = старшее слово (high word) — байты S (знак), E (экспонента), A (мантисса)

Для восстановления корректного float выполняется операция `(reg_hi << 16) | reg_lo`, после чего 32-битное значение интерпретируется как IEEE 754 float через `memcpy`.

Драйвер выполняет следующие задачи:
1. Получение сырых Modbus-регистров расхода и объёма через модуль `modbus_poller`.
2. Конвертация word-swapped регистров в стандартный IEEE 754 float.
3. Проверка валидности полученных значений (конечность, неотрицательность).
4. Контроль онлайн-статуса устройства на шине Modbus.

Используется в системе управления обратным осмосом для мониторинга расхода воды на входе, рециркуляции концентрата и выхода пермеата.

## Константы и макроопределения (#define)

### Публичные (flowmeter.h)

| Константа | Значение | Описание |
|-----------|----------|----------|
| `FLOW_CHANNEL_COUNT` | `4` | Количество каналов расходомера. Расходомер УРЖ2КМ имеет 4 измерительных канала (Q1-Q4 / V1-V4). |
| `FLOW_CH_INLET` | `0` | Индекс канала Q1 — расход на входе системы (после насоса подачи). Измеряет общий объём воды, поступающей на мембраны. |
| `FLOW_CH_CONC1` | `1` | Индекс канала Q2 — расход рециркуляции концентрата 1-й ступени обратного осмоса. Измеряет объём концентрата, возвращаемого на вход 1-й ступени. |
| `FLOW_CH_PERM2` | `2` | Индекс канала Q3 — расход пермеата 2-й ступени обратного осмоса. Измеряет объём очищенной воды, прошедшей через обе ступени мембран. |
| `FLOW_CH_CONC2` | `3` | Индекс канала Q4 — расход концентрата 2-й ступени обратного осмоса. Измеряет объём отбрасываемого концентрата на выходе 2-й ступени. |

## Типы данных (typedef / struct)

### Публичные (flowmeter.h)

#### `flowmeter_data_t`
Агрегированная структура данных расходомера. Содержит мгновенный расход, накопленный объём, флаги валидности каналов и статус устройства.

| Поле | Тип | Описание |
|------|-----|----------|
| `flow_m3h` | `float[FLOW_CHANNEL_COUNT]` | Массив мгновенных расходов Q1-Q4 в кубических метрах в час (м3/ч). Индексация: `[0]` = Q1 (вход), `[1]` = Q2 (рециркуляция концентрата 1), `[2]` = Q3 (пермеат 2), `[3]` = Q4 (концентрат 2). Значения получены конвертацией word-swapped Modbus-регистров в IEEE 754 float. |
| `volume_m3` | `float[FLOW_CHANNEL_COUNT]` | Массив накопленных объёмов V1-V4 в кубических метрах (м3). Индексация аналогична `flow_m3h`. Значения представляют суммарный объём жидкости, прошедший через каждый канал с момента последнего сброса счётчика прибора. |
| `channel_ok` | `bool[FLOW_CHANNEL_COUNT]` | Массив флагов валидности данных для каждого канала. `true` означает, что: устройство онлайн (`device_online == true`), значение расхода конечное (`isfinite`) и неотрицательное (>= 0), значение объёма конечное и неотрицательное. `false` может означать отсутствие связи с прибором или получение некорректных данных (NaN, Inf, отрицательные значения). |
| `device_online` | `bool` | Флаг доступности расходомера УРЖ2КМ на шине Modbus. `true` означает, что устройство отвечает на запросы. Определяется функцией `modbus_poller_is_device_online(MB_ADDR_URZH2KM)`. |

## Функции

### `static float urzh_regs_to_float(uint16_t reg_lo, uint16_t reg_hi)` (внутренняя)

**Объявление:** `flowmeter.c`, строка 24 (статическая функция, не экспортируется)

**Описание:**
Конвертирует два 16-битных Modbus-регистра из нестандартного word-swapped формата расходомера УРЖ2КМ в стандартный IEEE 754 float.

Алгоритм:
1. Объединяет два 16-битных регистра в одно 32-битное значение: `ieee = (reg_hi << 16) | reg_lo`.
2. Копирует 32-битное целое в переменную типа `float` через `memcpy()` (безопасная конвертация без нарушения strict aliasing).

Формат УРЖ2КМ:
- `reg_lo` (первый регистр) содержит младшее 16-битное слово IEEE 754 float.
- `reg_hi` (второй регистр) содержит старшее 16-битное слово IEEE 754 float (знак, экспонента, старшие биты мантиссы).

**Параметры:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `reg_lo` | `uint16_t` | Младшее слово (low word) — первый Modbus-регистр пары. Содержит младшие 16 бит IEEE 754 float. |
| `reg_hi` | `uint16_t` | Старшее слово (high word) — второй Modbus-регистр пары. Содержит старшие 16 бит IEEE 754 float (знак, экспонента). |

**Возвращаемое значение:**

| Тип | Описание |
|-----|----------|
| `float` | Восстановленное значение с плавающей запятой IEEE 754. Может быть NaN или Inf, если исходные регистры содержат некорректные данные. |

### `void flowmeter_init(void)`

**Объявление:** `flowmeter.h`, строка 32

**Описание:**
Инициализация драйвера расходомера. Должна быть вызвана один раз при старте системы перед использованием любых других функций модуля.

Выполняемые действия:
1. Обнуление всей структуры данных `s_data` с помощью `memset()`. Все расходы, объёмы устанавливаются в 0.0, все флаги — в `false`.
2. Вывод информационного сообщения в лог: "Драйвер расходомера УРЖ2КМ инициализирован".

**Параметры:** нет

**Возвращаемое значение:** нет (`void`)

---

### `void flowmeter_update(void)`

**Объявление:** `flowmeter.h`, строка 33

**Описание:**
Цикл обновления данных расходомера. Должна вызываться периодически (например, из основного цикла опроса). При каждом вызове выполняет:

1. **Получение сырых данных расхода:** вызывает `modbus_poller_get_flow_raw()` для получения массива из `CID_FLOW_RATE_REG_COUNT` (8) Modbus-регистров, содержащих данные мгновенного расхода Q1-Q4 (4 канала × 2 регистра).
2. **Получение сырых данных объёма:** вызывает `modbus_poller_get_volume_raw()` для получения массива из `CID_FLOW_VOL_REG_COUNT` (**8**, было 16) Modbus-регистров, содержащих данные накопленного объёма V1-V4 (4 канала × 2 регистра). V5..V8 не сверены с протоколом ТЕСС, до сверки игнорируются.
3. **Проверка онлайн-статуса** (Phase-5: getter возвращает `ESP_ERR_INVALID_STATE` до первого опроса; не-OK эквивалентен offline): `online = modbus_poller_is_device_online(MB_ADDR_URZH2KM) AND err_flow == ESP_OK AND err_vol == ESP_OK`.
4. **Конвертация данных:** для каждого из 4 каналов:
   - Преобразует пару регистров расхода `flow_raw[ch*2]`, `flow_raw[ch*2+1]` в float через `urzh_regs_to_float()` и записывает в `snapshot.flow_m3h[ch]`.
   - Преобразует пару регистров объёма `vol_raw[ch*2]`, `vol_raw[ch*2+1]` в float через `urzh_regs_to_float()` и записывает в `snapshot.volume_m3[ch]`.
5. **Валидация:** для каждого канала устанавливает `channel_ok[ch]` в `true` только при одновременном выполнении всех условий:
   - Устройство онлайн (`online == true`)
   - Расход конечный (`isfinite(q) == true`)
   - Расход неотрицательный (`q >= 0.0f`)
   - Объём конечный (`isfinite(v) == true`)
   - Объём неотрицательный (`v >= 0.0f`)
6. **Атомарная публикация:** локальный `snapshot` копируется в `s_data` под spinlock'ом `s_data_mux`.

**Параметры:** нет

**Возвращаемое значение:** нет (`void`)

### `float flowmeter_get_flow(uint8_t ch)`

**Объявление:** `flowmeter.h`, строка 35

**Описание:**
Возвращает текущее значение мгновенного расхода указанного канала в м3/ч. Выполняет проверку корректности номера канала и валидности данных.

**Параметры:**

| Параметр | Тип | Описание |
|----------|-----|----------|

**Возвращаемое значение:**

| Тип | Описание |
|-----|----------|
| `float` | Мгновенный расход в м3/ч. Возвращает `NAN`, если: номер канала >= `FLOW_CHANNEL_COUNT` (4), или данные канала не валидны (`channel_ok[ch] == false`). |

## Алгоритм работы

### Формат данных УРЖ2КМ
Расходомер УРЖ2КМ передаёт числа с плавающей запятой в формате word-swapped IEEE 754. Каждое значение float занимает 2 последовательных Modbus-регистра (16 бит каждый):
- Регистр с чётным смещением (`ch * 2`) = младшее слово (low word)
- Регистр с нечётным смещением (`ch * 2 + 1`) = старшее слово (high word)

Для восстановления корректного IEEE 754 float выполняется сборка 32-битного числа:
```
uint32_t ieee = (high_word << 16) | low_word;
```
Затем через `memcpy` результат интерпретируется как `float`.

### Валидация данных
Для каждого канала проверяется:
1. Устройство доступно на шине Modbus
2. Значение расхода является конечным числом (не NaN, не Inf) и неотрицательным
3. Значение объёма является конечным числом и неотрицательным

Если любое из условий не выполняется, канал помечается как невалидный (`channel_ok = false`).
