# Документация: analog_input (Драйвер аналоговых входов)

**Файлы:**
- Заголовочный: `include/analog_input.h`
- Реализация: `analog_input.c`

---

## Общее описание

Драйвер аналоговых входов для модуля **Waveshare AI 8CH** (8-канальный модуль аналогового ввода с интерфейсом Modbus). Модуль принимает токовые сигналы 4-20 мА от датчиков давления и температуры и преобразует их в цифровые значения (raw 0-65535).

Драйвер выполняет следующие задачи:
1. Получение сырых данных из Modbus-регистров через модуль `modbus_poller`.
2. Цифровая фильтрация методом скользящего среднего с окном N=8.
3. Преобразование сырых значений (0 .. `ADC_RAW_MAX`) в инженерные единицы (бар, градусы Цельсия) по линейной шкале.
4. Пересчёт сырых значений в значения тока (мА) для диагностики.
5. Детекция обрыва датчика (ток ниже порога ~4 мА).
6. Контроль онлайн-статуса устройства на шине Modbus.

Используется в системе управления обратным осмосом для мониторинга давлений на различных ступенях и температуры воды.

## Константы и макроопределения (#define)

### Публичные (analog_input.h)

| Константа | Значение | Описание |
|-----------|----------|----------|
| `AI_CHANNEL_COUNT` | `8` | Общее количество аналоговых каналов модуля Waveshare AI 8CH. Соответствует 8 физическим входам модуля. |
| `AI_CH_P1` | `0` | Индекс канала P1 — давление после насоса подачи. Диапазон измерения: 0-6 бар. |
| `AI_CH_P2` | `1` | Индекс канала P2 — давление после фильтра. Диапазон измерения: 0-6 бар. |
| `AI_CH_P3` | `2` | Индекс канала P3 — давление после насоса 1-й ступени обратного осмоса. Диапазон измерения: 0-40 бар. |
| `AI_CH_P4` | `3` | Индекс канала P4 — давление после насоса 2-й ступени обратного осмоса. Диапазон измерения: 0-10 бар. |
| `AI_CH_T` | `4` | Индекс канала T — температура воды. Диапазон измерения: 0-100 градусов Цельсия. |

### Приватные (analog_input.c)

| Константа | Значение | Описание |
|-----------|----------|----------|
| `MA_WINDOW` | `8` | Размер окна скользящего среднего. Определяет количество последних отсчётов, по которым вычисляется среднее арифметическое для фильтрации шума АЦП. |
| `FAULT_RAW_THRESHOLD` | `328` | Порог обнаружения обрыва датчика в единицах raw-значения. Составляет примерно 0.5% от `ADC_RAW_MAX`. Если усреднённое сырое значение канала ниже этого порога, это означает, что ток датчика упал ниже ~4.08 мА (ниже нижней границы диапазона 4-20 мА), что интерпретируется как обрыв провода или неисправность датчика. |
| `ADC_RAW_MAX` | `65535.0f` | Максимальное значение raw-кода АЦП (16-битное разрешение). Используется как делитель при нормализации сырого значения в диапазон 0.0 .. 1.0 для последующего линейного преобразования. |
| `CURRENT_LOOP_MIN_MA` | `4.0f` | Минимальный ток токовой петли 4-20 мА (соответствует raw = 0). Используется при пересчёте нормализованного значения в миллиамперы. |
| `CURRENT_LOOP_SPAN_MA` | `16.0f` | Размах (span) токовой петли: 20 - 4 = 16 мА. Множитель при пересчёте нормализованного значения в миллиамперы: `raw_ma = CURRENT_LOOP_MIN_MA + ratio * CURRENT_LOOP_SPAN_MA`. |
| `AI_ENABLED_CHANNELS` | `5` | Количество активных (задействованных) каналов (P1, P2, P3, P4, T). Каналы с индексами от `AI_ENABLED_CHANNELS` до `AI_CHANNEL_COUNT - 1` считаются резервными и отключаются при инициализации (`enabled = false`). |

## Типы данных (typedef / struct)

### Публичные (analog_input.h)

#### `ai_channel_data_t`
Структура данных одного аналогового канала.

| Поле | Тип | Описание |
|------|-----|----------|
| `value` | `float` | Текущее измеренное значение в инженерных единицах. Для каналов давления — бар, для канала температуры — градусы Цельсия. Вычисляется линейной интерполяцией из усреднённого raw-значения. |
| `raw_ma` | `float` | Текущее значение тока датчика в миллиамперах (мА). Вычисляется из raw-значения: `CURRENT_LOOP_MIN_MA + (raw / ADC_RAW_MAX) * CURRENT_LOOP_SPAN_MA`. Используется для диагностики состояния датчика и токовой петли. Диапазон: 4.0-20.0 мА при нормальной работе. |
| `fault` | `bool` | Флаг обрыва датчика. `true` означает, что усреднённое raw-значение ниже порога `FAULT_RAW_THRESHOLD` (ток ниже ~4 мА), что свидетельствует об обрыве провода или неисправности датчика. |
| `valid` | `bool` | Флаг актуальности данных. `true` означает, что устройство Waveshare AI онлайн (`device_online == true`) И нет обрыва датчика (`fault == false`). Если `valid == false`, значение `value` не следует использовать для управления. |

#### `ai_data_t`
Агрегированная структура данных всех аналоговых каналов.

| Поле | Тип | Описание |
|------|-----|----------|
| `channels` | `ai_channel_data_t[AI_CHANNEL_COUNT]` | Массив из 8 элементов — данные каждого аналогового канала. Индексация по константам `AI_CH_P1` ... `AI_CH_T`. Каналы с индексами от `AI_ENABLED_CHANNELS` (5) до `AI_CHANNEL_COUNT - 1` (7) зарезервированы и будут иметь `valid == false`. |
| `device_online` | `bool` | Флаг доступности устройства Waveshare AI 8CH на шине Modbus. `true` означает, что устройство отвечает на запросы. Определяется функцией `modbus_poller_is_device_online()`. |

### Приватные (analog_input.c)

#### `ai_ch_cfg_t`
Конфигурация одного аналогового канала (внутренняя структура, не экспортируется).

| Поле | Тип | Описание |
|------|-----|----------|
| `range_min` | `float` | Минимальное значение инженерной единицы, соответствующее raw = 0 (ток 4 мА). Например, 0.0 бар для каналов давления. |
| `range_max` | `float` | Максимальное значение инженерной единицы, соответствующее raw = `ADC_RAW_MAX` (ток 20 мА). Например, 6.0 бар для P1 и P2, 40.0 бар для P3, 10.0 бар для P4, 100.0 °C для T. |
| `enabled` | `bool` | Признак того, что канал активен и подлежит обработке. Каналы 0 .. `AI_ENABLED_CHANNELS - 1` (0-4) включены (`true`), каналы `AI_ENABLED_CHANNELS` .. `AI_CHANNEL_COUNT - 1` (5-7) выключены (`false`, резерв). Если `enabled == false`, данные канала не обрабатываются, а `valid` устанавливается в `false`. |

## Внутренние статические переменные (analog_input.c)

| Переменная | Тип | Описание |
|------------|-----|----------|
| `TAG` | `const char *` | Тег для системы логирования ESP-IDF. Значение: `"ai_drv"`. Используется во всех вызовах `ESP_LOGx()` для идентификации сообщений этого модуля. |
| `s_config` | `ai_ch_cfg_t[AI_CHANNEL_COUNT]` | Массив конфигураций каналов. Инициализируется в `analog_input_init()`. Хранит диапазоны инженерных единиц (`range_min`, `range_max`) и признак активности (`enabled`) для каждого из 8 каналов. |
| `s_ma_buf` | `uint16_t[AI_CHANNEL_COUNT][MA_WINDOW]` | Кольцевой буфер скользящего среднего. Двумерный массив: для каждого из 8 каналов хранится последние `MA_WINDOW` (8) сырых значений raw из АЦП. Используется для вычисления среднего арифметического с целью подавления шума. |
| `s_ma_idx` | `uint8_t` | Текущий индекс записи в кольцевом буфере скользящего среднего. Инкрементируется при каждом вызове `analog_input_update()` и оборачивается через `% MA_WINDOW`. Значения: 0..7. |
| `s_ma_filled` | `bool` | Флаг полного заполнения буфера скользящего среднего. Устанавливается в `true`, когда индекс `s_ma_idx` совершает полный оборот (возвращается к 0). До этого момента среднее вычисляется по фактически накопленным отсчётам (`s_ma_idx` элементов), после — по полному окну (`MA_WINDOW` элементов). |
| `s_data` | `ai_data_t` | Текущие обработанные данные всех аналоговых каналов. Обновляется при каждом вызове `analog_input_update()`. Копируется в пользовательский буфер через `analog_input_get_data()`. |

## Функции

### `void analog_input_init(void)`

**Объявление:** `analog_input.h`, строка 39

**Описание:**
Инициализация драйвера аналоговых входов. Должна быть вызвана один раз при старте системы перед использованием любых других функций модуля.

Выполняемые действия:
1. Настройка конфигурации каналов 0-4 (P1, P2, P3, P4, T) — задание диапазонов инженерных единиц и установка флага `enabled = true`:
   - P1 (канал 0): 0.0 - 6.0 бар
   - P2 (канал 1): 0.0 - 6.0 бар
   - P3 (канал 2): 0.0 - 40.0 бар
   - P4 (канал 3): 0.0 - 10.0 бар
   - T (канал 4): 0.0 - 100.0 °C
2. Отключение резервных каналов `AI_ENABLED_CHANNELS` .. `AI_CHANNEL_COUNT - 1` (5-7) в цикле (`enabled = false`).
3. Обнуление буфера скользящего среднего `s_ma_buf`.
4. Сброс индекса буфера `s_ma_idx = 0` и флага заполнения `s_ma_filled = false`.
5. Обнуление структуры данных `s_data`.
6. Вывод информационного сообщения в лог.

**Параметры:** нет

**Возвращаемое значение:** нет (`void`)

### `void analog_input_update(void)`

**Объявление:** `analog_input.h`, строка 40

**Описание:**
Цикл обновления данных аналоговых входов. Должна вызываться периодически (например, из основного цикла опроса). При каждом вызове выполняет:

1. **Получение сырых данных:** вызывает `modbus_poller_get_ai_raw()` для получения массива raw-значений из `CID_AI_REG_COUNT` Modbus-регистров.
2. **Проверка онлайн-статуса:** вызывает `modbus_poller_is_device_online(MB_ADDR_WAVESHARE_AI)` и сохраняет результат в `s_data.device_online`.
3. **Запись в кольцевой буфер:** записывает полученные raw-значения всех 8 каналов в текущую позицию `s_ma_idx` буфера `s_ma_buf`, затем инкрементирует индекс (с оборотом по модулю `MA_WINDOW`).
4. **Вычисление скользящего среднего:** для каждого активного канала (`enabled == true`) суммирует значения из буфера и делит на количество накопленных отсчётов (от 1 до `MA_WINDOW`).
5. **Детекция обрыва:** если усреднённое значение ниже `FAULT_RAW_THRESHOLD` (328), устанавливает `fault = true`.
6. **Линейное преобразование:** пересчитывает усреднённое raw-значение в инженерные единицы по формуле:
   ```
   ratio = avg / ADC_RAW_MAX
   value = range_min + ratio * (range_max - range_min)
   ```
7. **Пересчёт в мА:** вычисляет ток датчика по формуле `raw_ma = CURRENT_LOOP_MIN_MA + ratio * CURRENT_LOOP_SPAN_MA`.
8. **Установка флага валидности:** `valid = device_online AND NOT fault`.

Для неактивных каналов (`enabled == false`) устанавливается `valid = false`, остальные поля не обновляются.

**Параметры:** нет

**Возвращаемое значение:** нет (`void`)

## Алгоритм работы

### Скользящее среднее
Для подавления шума АЦП используется скользящее среднее с окном 8 отсчётов. Сырые значения записываются в кольцевой буфер `s_ma_buf`. При первых 7 вызовах `analog_input_update()` (до полного заполнения буфера) среднее вычисляется по фактически накопленным отсчётам. После полного заполнения — по всем 8 значениям в буфере.

### Линейное преобразование
Raw-значение 0 соответствует минимуму диапазона (`CURRENT_LOOP_MIN_MA` = 4 мА), `ADC_RAW_MAX` (65535) — максимуму (20 мА). Формула преобразования:
```
value = range_min + (avg / ADC_RAW_MAX) * (range_max - range_min)
```

### Детекция обрыва
Если усреднённое raw-значение < `FAULT_RAW_THRESHOLD` (328, примерно 0.5% от `ADC_RAW_MAX`), это означает ток ниже ~4.08 мА, что интерпретируется как обрыв провода датчика.
