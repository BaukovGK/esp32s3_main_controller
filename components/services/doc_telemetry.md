# telemetry -- Расчетные параметры установки обратного осмоса

## Описание

Модуль `telemetry` выполняет расчет производных (вычисляемых) параметров установки обратного осмоса на основе данных от аналоговых датчиков давления, расходомеров и кондуктометров. Вычисляются: перепад давления на фильтре, суммарная подача 1-й ступени, степень извлечения (recovery) для 2-й ступени и системы в целом, а также селективность мембран 1-й и 2-й ступеней. Все значения доступны через указатель только для чтения.

**Файлы:**
- Заголовочный: `include/telemetry.h`
- Реализация: `telemetry.c`

## Структуры данных

### `telemetry_data_t` -- Расчетные параметры

| Поле                    | Тип     | Описание                                                                      |
|-------------------------|---------|-------------------------------------------------------------------------------|
| `filter_dp`             | `float` | Перепад давления на фильтре: P1 - P2, бар. NAN если P1 или P2 недостоверны   |
| `stage1_feed_m3h`       | `float` | Суммарная подача 1-й ступени: Q1 + Q2, куб.м/ч. NAN если Q1 или Q2 недостоверны |
| `stage2_recovery_pct`   | `float` | Степень извлечения 2-й ступени: Q3/(Q3+Q4)*100, %. NAN если Q3/Q4 недостоверны или (Q3+Q4) < 0.001 |
| `system_recovery_pct`   | `float` | Общая степень извлечения системы: Q3/Q1*100, %. NAN если Q3 или Q1 недостоверны или Q1 < 0.001 |
| `stage1_selectivity`    | `float` | Селективность мембран 1-й ступени: (sigma1-sigma2)/sigma1*100, %. NAN если sigma1 или sigma2 недостоверны или sigma1 < 0.01 |
| `stage2_selectivity`    | `float` | Селективность мембран 2-й ступени: (sigma2-sigma3)/sigma2*100, %. NAN если sigma2 или sigma3 недостоверны или sigma2 < 0.01 |
| `valid`                 | `bool`  | Признак достоверности данных: `true` если `filter_dp` не NAN (т.е. базовые датчики давления работают) |

**Обозначения каналов датчиков, используемых при расчете:**
- `AI_CH_P1` -- аналоговый вход давления P1 (вход в систему)
- `AI_CH_P2` -- аналоговый вход давления P2 (после фильтра)
- `FLOW_CH_INLET` -- расходомер Q1 (входной поток)
- `FLOW_CH_CONC1` -- расходомер Q2 (концентрат 1-й ступени)
- `FLOW_CH_PERM2` -- расходомер Q3 (пермеат 2-й ступени)
- `FLOW_CH_CONC2` -- расходомер Q4 (концентрат 2-й ступени)
- `COND_CH_FEED` -- кондуктометр sigma1 (исходная вода)
- `COND_CH_PERM1` -- кондуктометр sigma2 (пермеат 1-й ступени)
- `COND_CH_PERM2` -- кондуктометр sigma3 (пермеат 2-й ступени)

> **Примечание:** с 2026-05-09 в `conductivity` доступно **4** канала (`COND_CHANNEL_COUNT = 4`); добавлен `COND_CH_CONC` (концентрат, slave 11 X2/t2). В расчётах телеметрии этот канал пока не используется — только информационно публикуется в MQTT/HMI.

## Публичные функции

### `telemetry_init`

```c
void telemetry_init(void);
```

**Описание:** Инициализирует модуль телеметрии. Обнуляет структуру `s_data` (все поля = 0, `valid = false`). Логирует факт инициализации.

**Параметры:** нет

**Возвращает:** ничего (`void`)

---

### `telemetry_update`

```c
void telemetry_update(void);
```

**Описание:** Выполняет пересчет всех расчетных параметров на основе текущих показаний датчиков. Должна вызываться периодически из основного цикла управления. Последовательность вычислений:

1. **Перепад на фильтре (`filter_dp`):** Считывает P1 и P2 из аналоговых входов. Если оба значения достоверны (не NAN), вычисляет разность P1 - P2. Иначе устанавливает NAN.

2. **Подача 1-й ступени (`stage1_feed_m3h`):** Считывает расходы Q1 (вход) и Q2 (концентрат 1-й ступени). Если оба достоверны, вычисляет сумму Q1 + Q2. Иначе NAN.

3. **Извлечение 2-й ступени (`stage2_recovery_pct`):** Считывает расходы Q3 (пермеат 2-й ступени) и Q4 (концентрат 2-й ступени). Если оба достоверны и их сумма > 0.001 куб.м/ч, вычисляет Q3/(Q3+Q4)*100. Иначе NAN. Защита от деления на ноль при минимальном расходе.

4. **Общее извлечение (`system_recovery_pct`):** Если Q3 и Q1 достоверны и Q1 > 0.001, вычисляет Q3/Q1*100. Иначе NAN.

5. **Селективность 1-й ступени (`stage1_selectivity`):** Считывает электропроводность sigma1 (исходная вода) и sigma2 (пермеат 1-й ступени). Если оба достоверны и sigma1 > 0.01, вычисляет (sigma1-sigma2)/sigma1*100. Иначе NAN.

6. **Селективность 2-й ступени (`stage2_selectivity`):** Считывает sigma2 и sigma3 (пермеат 2-й ступени). Если оба достоверны и sigma2 > 0.01, вычисляет (sigma2-sigma3)/sigma2*100. Иначе NAN.

7. **Флаг достоверности (`valid`):** Устанавливается в `true`, если `filter_dp` не NAN (минимальный критерий работоспособности датчиков давления).

**Параметры:** нет

**Возвращает:** ничего (`void`)

---

### `telemetry_get`

```c
const telemetry_data_t *telemetry_get(void);
```

**Описание:** Возвращает указатель на структуру с текущими расчетными параметрами. Указатель `const` -- данные доступны только для чтения. Указатель действителен в течение всего времени работы программы (статическая переменная).

**Параметры:** нет

**Возвращает:** `const telemetry_data_t *` -- указатель на текущие расчетные данные.

## Формулы расчета

| Параметр               | Формула                          | Единицы | Условие корректности                    |
|------------------------|----------------------------------|---------|-----------------------------------------|
| Перепад на фильтре     | `P1 - P2`                       | бар     | P1 и P2 не NAN                          |
| Подача 1-й ступени     | `Q1 + Q2`                       | куб.м/ч | Q1 и Q2 не NAN                          |
| Извлечение 2-й ступени | `Q3 / (Q3 + Q4) * 100`          | %       | Q3, Q4 не NAN; (Q3+Q4) > 0.001         |
| Общее извлечение       | `Q3 / Q1 * 100`                 | %       | Q3, Q1 не NAN; Q1 > 0.001              |
| Селективность 1-й ст.  | `(sigma1 - sigma2) / sigma1 * 100` | %    | sigma1, sigma2 не NAN; sigma1 > 0.01   |
| Селективность 2-й ст.  | `(sigma2 - sigma3) / sigma2 * 100` | %    | sigma2, sigma3 не NAN; sigma2 > 0.01   |
