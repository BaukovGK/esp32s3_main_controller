# config_manager -- Менеджер конфигурации

## Описание

Модуль `config_manager` отвечает за хранение, загрузку и сохранение конфигурационных параметров установки обратного осмоса в энергонезависимой памяти (NVS). При инициализации загружаются значения из NVS; если ключ отсутствует -- используется значение по умолчанию. После загрузки все параметры проходят валидацию (clamping) -- если значение выходит за допустимый диапазон, оно заменяется значением по умолчанию. Конфигурация доступна всем модулям системы через указатель только для чтения.

**Потокобезопасность:** spinlock (`portMUX_TYPE s_mux`) защищает `s_config` при записи (все setter-функции `config_manager_set_*`) и при копировании всей конфигурации через `config_manager_get_copy()`. Чтение отдельных полей (`float`, `int32_t`) через `config_manager_get()` атомарно на ESP32 и не требует блокировки.

**Файлы:**
- Заголовочный: `include/config_manager.h`
- Реализация: `config_manager.c`

## Внутренние (static) функции

### `load_float`

```c
static void load_float(const char *key, float *dst)
```

**Описание:** Загружает значение типа `float` из NVS по указанному ключу. Если ключ не найден (ошибка `ESP_ERR_NVS_NOT_FOUND` или другая), значение `*dst` остается без изменений (т.е. сохраняется значение по умолчанию, установленное ранее).

**Параметры:**
- `key` -- строка-ключ NVS
- `dst` -- указатель на переменную, куда записывается загруженное значение

---

### `load_i32`

```c
static void load_i32(const char *key, int32_t *dst)
```

**Описание:** Загружает значение типа `int32_t` из NVS по указанному ключу. При отсутствии ключа значение `*dst` не изменяется.

**Параметры:**
- `key` -- строка-ключ NVS
- `dst` -- указатель на переменную, куда записывается загруженное значение

---

### `load_str`

```c
static void load_str(const char *key, char *dst, size_t max_len)
```

**Описание:** Загружает строку из NVS по указанному ключу. Использует промежуточный буфер размером `NVS_STR_BUF_SIZE` (128) байт. Длина чтения определяется как `min(max_len, sizeof(buf))` -- если `max_len` меньше размера буфера, читается не более `max_len` байт; иначе не более `NVS_STR_BUF_SIZE`. Результат всегда завершается нуль-терминатором. При отсутствии ключа значение `dst` не изменяется.

**Параметры:**
- `key` -- строка-ключ NVS
- `dst` -- буфер-приемник строки
- `max_len` -- максимальная длина строки (включая нуль-терминатор)

---

### `clamp_float`

```c
static float clamp_float(float val, float min, float max, float def)
```

**Описание:** Проверяет, находится ли значение `val` в диапазоне `[min, max]`. Если значение выходит за границы (строго меньше `min` или строго больше `max`), возвращается значение по умолчанию `def`. Иначе возвращается `val` без изменений.

**Параметры:**
- `val` -- проверяемое значение
- `min` -- нижняя граница допустимого диапазона
- `max` -- верхняя граница допустимого диапазона
- `def` -- значение по умолчанию, возвращаемое при выходе за диапазон

**Возвращает:** `val` если в диапазоне, иначе `def`.

---

### `clamp_i32`

```c
static int32_t clamp_i32(int32_t val, int32_t min, int32_t max, int32_t def)
```

**Описание:** Аналог `clamp_float` для целочисленных значений `int32_t`. Проверяет диапазон и при выходе за границы возвращает значение по умолчанию.

**Параметры:**
- `val` -- проверяемое значение
- `min` -- нижняя граница допустимого диапазона
- `max` -- верхняя граница допустимого диапазона
- `def` -- значение по умолчанию

**Возвращает:** `val` если в диапазоне, иначе `def`.

### `validate_pressure`

```c
static void validate_pressure(config_pressure_t *p)
```

**Описание:** Применяет clamping ко всем полям секции давления, используя именованные макросы границ (`CFG_P1_MAX_LO`/`HI`, `CFG_P3_MAX_LO`/`HI`, `CFG_P4_MAX_LO`/`HI`, `CFG_FILTER_DP_LO`/`HI`). При выходе поля за допустимый диапазон оно заменяется соответствующим значением из `s_defaults`.

**Параметры:**
- `p` -- указатель на структуру `config_pressure_t`, поля которой валидируются in-place

---

### `validate_doser`

```c
static void validate_doser(config_doser_t *d)
```

**Описание:** Применяет clamping к полям дозатора (`CFG_DOSER_RUN_LO`/`HI`, `CFG_DOSER_CYC_LO`/`HI`). Дополнительно проверяет, что `run_time_min < cycle_time_min`. Если это условие нарушено, оба поля сбрасываются к значениям из `s_defaults` и выводится предупреждение в лог.

**Параметры:**
- `d` -- указатель на структуру `config_doser_t`, поля которой валидируются in-place

---

### `validate_washing`

```c
static void validate_washing(config_washing_t *w)
```

**Описание:** Применяет clamping ко всем семи полям секции промывки, используя соответствующие макросы границ (`CFG_WASH_TARGET_*`, `CFG_WASH_MAX_*`, `CFG_WASH_OVER_*`, `CFG_WASH_HYST_*`, `CFG_WASH_HEAT_*`, `CFG_WASH_SUP_*`, `CFG_WASH_DRN_*`).

**Параметры:**
- `w` -- указатель на структуру `config_washing_t`, поля которой валидируются in-place

```c
static void validate_timeouts(config_timeouts_t *t)
```

```c
static void validate_mqtt(config_mqtt_t *m)
```

**Описание:** Применяет clamping к `publish_interval_s` (`CFG_MQTT_INTV_LO`/`HI`). Нормализует поле `enabled` к 0 или 1 (любое ненулевое значение приводится к 1). Проверяет строковые поля: если `broker_uri` или `client_id` пусты, заменяет их значениями из `s_defaults`.

**Параметры:**
- `m` -- указатель на структуру `config_mqtt_t`, поля которой валидируются in-place

## Публичные функции

### `config_manager_init`

```c
esp_err_t config_manager_init(void);
```

**Описание:** Инициализирует менеджер конфигурации. Выполняет следующую последовательность действий:

1. Копирует значения по умолчанию из `s_defaults` в рабочую конфигурацию `s_config`.
2. Поочередно загружает все параметры из NVS. Если какой-либо ключ отсутствует в NVS, соответствующее поле сохраняет значение по умолчанию.
3. Выполняет валидацию (clamping) каждого загруженного параметра через функции `validate_*`: если значение выходит за допустимый диапазон, оно заменяется значением по умолчанию.
4. Дополнительная проверка дозатора: если `run_time_min >= cycle_time_min`, оба поля сбрасываются к дефолтам.
5. Дополнительная проверка строковых полей MQTT: если `broker_uri` или `client_id` пусты, они заменяются значениями по умолчанию.
6. Нормализация поля `enabled` в MQTT: любое ненулевое значение приводится к 1.
7. Выводит в лог информацию о загруженной конфигурации.

**Параметры:** нет

**Возвращает:** `ESP_OK` -- всегда успешно (отсутствие ключей в NVS не считается ошибкой).

### `config_manager_get`

```c
const plant_config_t *config_manager_get(void);
```

**Описание:** Возвращает указатель на текущую конфигурацию установки. Указатель является `const` -- конфигурацию нельзя изменять напрямую; для изменения нужно использовать соответствующие функции `config_manager_set_*`. Указатель действителен на протяжении всей работы программы (указывает на статическую переменную). Для чтения отдельных полей (`float`, `int32_t`) дополнительная синхронизация не требуется -- чтение атомарно на ESP32.

**Параметры:** нет

**Возвращает:** `const plant_config_t *` -- указатель на текущую конфигурацию (только для чтения).
