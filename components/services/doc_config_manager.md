# config_manager -- Менеджер конфигурации

## Описание

Модуль `config_manager` отвечает за хранение, загрузку и сохранение конфигурационных параметров установки обратного осмоса в энергонезависимой памяти (NVS). При инициализации загружаются значения из NVS; если ключ отсутствует -- используется значение по умолчанию. После загрузки все параметры проходят валидацию (clamping) -- если значение выходит за допустимый диапазон, оно заменяется значением по умолчанию. Конфигурация доступна всем модулям системы через указатель только для чтения.

**Файлы:**
- Заголовочный: `include/config_manager.h`
- Реализация: `config_manager.c`

| `hysteresis_C`    | `float`   | 2.0          | Гистерезис включения/выключения ТЭНа, C              |
| `heat_timeout_min`| `int32_t` | 30           | Максимальное время фазы нагрева, минуты               |
| `supply_time_min` | `int32_t` | 20           | Длительность фазы подачи промывочного раствора, минуты |

## Внутренние (static) функции

### `load_float`

```c
static void load_float(const char *key, float *dst)
```

**Описание:** Загружает значение типа `float` из NVS по указанному ключу. Если ключ не найден (ошибка `ESP_ERR_NVS_NOT_FOUND` или другая), значение `*dst` остается без изменений (т.е. сохраняется значение по умолчанию, установленное ранее).

**Параметры:**
- `key` -- строка-ключ NVS
- `dst` -- указатель на переменную, куда записывается загруженное значение

---

### `load_i32`

```c
static void load_i32(const char *key, int32_t *dst)
```

**Описание:** Загружает значение типа `int32_t` из NVS по указанному ключу. При отсутствии ключа значение `*dst` не изменяется.

**Параметры:**
- `key` -- строка-ключ NVS
- `dst` -- указатель на переменную, куда записывается загруженное значение

---

### `load_str`

```c
static void load_str(const char *key, char *dst, size_t max_len)
```

**Описание:** Загружает строку из NVS по указанному ключу. Использует промежуточный буфер размером 64 байта. Если `max_len` превышает 64, она ограничивается до 64. Результат всегда завершается нуль-терминатором. При отсутствии ключа значение `dst` не изменяется.

**Параметры:**
- `key` -- строка-ключ NVS
- `dst` -- буфер-приемник строки
- `max_len` -- максимальная длина строки (включая нуль-терминатор)

---

### `clamp_float`

```c
static float clamp_float(float val, float min, float max, float def)
```

**Описание:** Проверяет, находится ли значение `val` в диапазоне `[min, max]`. Если значение выходит за границы (строго меньше `min` или строго больше `max`), возвращается значение по умолчанию `def`. Иначе возвращается `val` без изменений.

**Параметры:**
- `val` -- проверяемое значение
- `min` -- нижняя граница допустимого диапазона
- `max` -- верхняя граница допустимого диапазона
- `def` -- значение по умолчанию, возвращаемое при выходе за диапазон

**Возвращает:** `val` если в диапазоне, иначе `def`.

---

### `clamp_i32`

```c
static int32_t clamp_i32(int32_t val, int32_t min, int32_t max, int32_t def)
```

**Описание:** Аналог `clamp_float` для целочисленных значений `int32_t`. Проверяет диапазон и при выходе за границы возвращает значение по умолчанию.

**Параметры:**
- `val` -- проверяемое значение
- `min` -- нижняя граница допустимого диапазона
- `max` -- верхняя граница допустимого диапазона
- `def` -- значение по умолчанию

**Возвращает:** `val` если в диапазоне, иначе `def`.

## Публичные функции

### `config_manager_init`

```c
esp_err_t config_manager_init(void);
```

**Описание:** Инициализирует менеджер конфигурации. Выполняет следующую последовательность действий:

1. Копирует значения по умолчанию из `s_defaults` в рабочую конфигурацию `s_config`.
2. Поочередно загружает все параметры из NVS. Если какой-либо ключ отсутствует в NVS, соответствующее поле сохраняет значение по умолчанию.
3. Выполняет валидацию (clamping) каждого загруженного параметра: если значение выходит за допустимый диапазон, оно заменяется значением по умолчанию.
4. Дополнительная проверка строковых полей MQTT: если `broker_uri` или `client_id` пусты, они заменяются значениями по умолчанию.
5. Нормализация поля `enabled` в MQTT: любое ненулевое значение приводится к 1.
6. Выводит в лог информацию о загруженной конфигурации.

**Параметры:** нет

**Возвращает:** `ESP_OK` -- всегда успешно (отсутствие ключей в NVS не считается ошибкой).

---

### `config_manager_get`

```c
const plant_config_t *config_manager_get(void);
```

**Описание:** Возвращает указатель на текущую конфигурацию установки. Указатель является `const` -- конфигурацию нельзя изменять напрямую; для изменения нужно использовать соответствующие функции `config_manager_set_*`. Указатель действителен на протяжении всей работы программы (указывает на статическую переменную).

**Параметры:** нет

**Возвращает:** `const plant_config_t *` -- указатель на текущую конфигурацию (только для чтения).

---

### `config_manager_set_pressure`

```c
esp_err_t config_manager_set_pressure(const config_pressure_t *cfg);
```

**Описание:** Обновляет секцию конфигурации давления. Копирует переданную структуру в `s_config.pressure` и сохраняет все четыре параметра в NVS (ключи: `p1_max`, `p3_max`, `p4_max`, `filt_dp`). Валидация при записи не выполняется -- предполагается, что вызывающий код передает корректные значения.

**Параметры:**
- `cfg` -- указатель на структуру `config_pressure_t` с новыми значениями

**Возвращает:** `ESP_OK` -- всегда.
