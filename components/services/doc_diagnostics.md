# diagnostics -- Сбор системной диагностики

## Описание

Модуль `diagnostics` обеспечивает сбор диагностической информации о состоянии системы ESP32. Собираются три категории данных:

1. **Система:** свободная и минимальная свободная память кучи (heap), время работы (uptime).
2. **Задачи FreeRTOS:** свободный стек (stack high water mark) для зарегистрированных задач (до 6 штук).
3. **Modbus:** количество ошибок и онлайн-статус для четырех slave-устройств с адресами, определёнными в `board_config.h` (`MB_ADDR_WAVESHARE_AI`, `MB_ADDR_URZH2KM`, `MB_ADDR_SL21_201`, `MB_ADDR_SL21_101`).

Модуль работает по принципу "снимка" (snapshot): при вызове `diagnostics_collect()` все данные собираются единовременно и копируются в предоставленную вызывающим кодом структуру.

**Файлы:**
- Заголовочный: `include/diagnostics.h`
- Реализация: `diagnostics.c`

## Структуры данных

### `diagnostics_data_t` -- Диагностический снимок

| Поле             | Тип                        | Описание                                                              |
|------------------|-----------------------------|----------------------------------------------------------------------|
| `free_heap`      | `uint32_t`                  | Текущий объем свободной памяти кучи, байты                           |
| `min_free_heap`  | `uint32_t`                  | Минимальный объем свободной памяти кучи за все время работы, байты    |
| `uptime_us`      | `int64_t`                   | Время работы системы с момента загрузки, микросекунды                 |
| `tasks[]`        | структура (см. ниже)        | Массив из `DIAG_MAX_TASKS` записей о задачах                         |
| `task_count`     | `int`                       | Фактическое число зарегистрированных задач                           |
| `mb_errors[4]`   | `uint32_t[4]`               | Количество ошибок Modbus для каждого из 4 slave-устройств            |
| `mb_online[4]`   | `bool[4]`                   | Онлайн-статус каждого из 4 slave-устройств Modbus                    |

#### Вложенная структура `tasks[i]`

| Поле         | Тип            | Описание                                                          |
|--------------|----------------|-------------------------------------------------------------------|
| `name`       | `const char *` | Имя задачи FreeRTOS (строковый литерал, переданный при регистрации) |
| `stack_free` | `uint32_t`     | Свободный стек задачи в байтах (high water mark * sizeof(StackType_t)) |

#### Индексация Modbus-устройств

| Индекс | Константа              | Slave-адрес | Описание                              |
|--------|------------------------|-------------|---------------------------------------|
| 0      | `MB_ADDR_WAVESHARE_AI` | 1           | Модуль аналоговых входов Waveshare    |
| 1      | `MB_ADDR_URZH2KM`     | 2           | Модуль URZH2KM                        |
| 2      | `MB_ADDR_SL21_201`    | 10          | Модуль SL21-201                        |
| 3      | `MB_ADDR_SL21_101`    | 11          | Модуль SL21-101                        |

## Публичные функции

### `diagnostics_register_task`

```c
void diagnostics_register_task(const char *name, TaskHandle_t handle);
```

**Описание:** Регистрирует задачу FreeRTOS для мониторинга свободного стека. Задачу можно зарегистрировать только если число уже зарегистрированных задач меньше `DIAG_MAX_TASKS` (6) и `handle` не равен `NULL`. При нарушении условий вызов игнорируется без ошибки.

Предполагается, что функция вызывается на этапе инициализации приложения, после создания задач через `xTaskCreate()` / `xTaskCreatePinnedToCore()`.

**Параметры:**
- `name` -- имя задачи для отображения в диагностике. Должен быть строковым литералом или указателем на строку с временем жизни, равным времени жизни программы (не копируется, хранится как указатель).
- `handle` -- хэндл задачи FreeRTOS, полученный при создании задачи. Не должен быть `NULL`.

**Возвращает:** ничего (`void`)

---

### `diagnostics_collect`

```c
void diagnostics_collect(diagnostics_data_t *out);
```

**Описание:** Собирает моментальный снимок (snapshot) диагностической информации и записывает его в предоставленную структуру. Последовательность сбора данных:

1. **Очистка:** Обнуление всей структуры `out` через `memset`.

2. **Система:**
   - `free_heap` = `esp_get_free_heap_size()` -- текущий объем свободной памяти кучи.
   - `min_free_heap` = `esp_get_minimum_free_heap_size()` -- минимальный объем свободной кучи за все время работы (water mark).
   - `uptime_us` = `esp_timer_get_time()` -- время работы в микросекундах.

3. **Стеки задач:**
   - `task_count` = число зарегистрированных задач.
   - Для каждой зарегистрированной задачи:
     - `tasks[i].name` -- имя задачи (указатель из регистрации).
     - `tasks[i].stack_free` -- свободный стек в байтах, рассчитанный как `uxTaskGetStackHighWaterMark(handle) * sizeof(StackType_t)`. Функция FreeRTOS `uxTaskGetStackHighWaterMark` возвращает минимальный оставшийся стек в единицах `StackType_t` (обычно 4 байта на ESP32), поэтому результат умножается на `sizeof(StackType_t)` для получения значения в байтах.

4. **Modbus:**
   - Для каждого slave-адреса из массива `s_mb_addrs` (цикл по `sizeof(s_mb_addrs)/sizeof(s_mb_addrs[0])` элементам):
     - `mb_errors[i]` = `modbus_poller_get_error_count(addr)` -- кумулятивное число ошибок связи.
     - `mb_online[i]` = `modbus_poller_is_device_online(addr)` -- текущий онлайн-статус устройства.

**Параметры:**
- `out` -- указатель на структуру `diagnostics_data_t`, куда будут записаны собранные данные. Не должен быть `NULL`.

**Возвращает:** ничего (`void`)

## Пример использования

```c
diagnostics_data_t diag;
diagnostics_collect(&diag);

printf("Heap: %lu free, %lu min\n",
       (unsigned long)diag.free_heap,
       (unsigned long)diag.min_free_heap);

printf("Uptime: %lld us\n", diag.uptime_us);

for (int i = 0; i < diag.task_count; i++) {
    printf("Task '%s': stack free = %lu bytes\n",
           diag.tasks[i].name,
           (unsigned long)diag.tasks[i].stack_free);
}

for (int i = 0; i < 4; i++) {
    printf("Modbus addr %d: %s, errors=%lu\n",
           s_mb_addrs[i],
           diag.mb_online[i] ? "ONLINE" : "OFFLINE",
           (unsigned long)diag.mb_errors[i]);
}
```
